# 東亜海域立志伝（nk1）

[简体中文](README.md) | [English](README.en.md) | **日本語**

南宋末期の東アジアの海を舞台にした、歴史航海・交易シミュレーションゲームです。Godot 4.6 で開発しています。

宋の宝祐三年（1255年）、興化の海口。プレイヤーは莆田・玉湖出身の士子、陳子龍となり、一艘の小さな沿岸船から身を起こします。泉州、明州、博多、耽羅（済州）、チャンパなどの港を行き来して商いをし、牙行の請負仕事を引き受け、海賊や差し押さえに立ち向かいます。やがて二十年後、元軍が南下し、海商の帳簿は王朝の存亡と絡み合っていきます。

> ゲーム内のテキストは現在中国語のみです。開発中のプロジェクトで、正式リリースはまだありません。

## ゲームの内容

- **時代と人物**：物語は1255年に始まり、宋元交代と崖山の戦いまで続きます。`data/characters.json` には75人の人物が収録され、そのうち41人は文天祥、張世傑、陸秀夫、蒲寿庚、賈似道、バヤン、クビライ、北条時頼などの実在の人物です。生没年などの史料との照合記録は `docs/` にあります。
- **港と海図**：興化、泉州、福州、温州、澎湖から、明州、耽羅、博多唐房、広州、薩摩、チャンパまで14の港があり、章が進むごとに開放されます。海図は実際の緯度経度と Natural Earth の海岸線をもとに描かれ、航程は航路に沿って計算され、季節風が出航の時期を左右します。
- **経済**：29種の商品（米、生糸、青白磁、香薬、倭銅、日本刀など）にはそれぞれ産地と消費地があります。港ごとの価格差、市場の厚み、売り崩し、禁制品、市舶司の抽解、牙行の請負、戦時の物価が利益に響きます。ほかに8種の船、船員と補給、港への投資、五段階の市舶司での肩書きがあります。
- **酒場と港**：酒場では噂を聞き、船員を雇い、人物と出会えます。港には市舶司、牙行、造船所、宿屋、行会、貢院、寺院なども並びます。
- **戦闘**：自分で船を操るリアルタイム海戦（風向き、舷側射撃、弾薬、浸水と火災、接舷白兵戦、士気）に加え、上陸襲撃、籠城戦と攻城戦、そして崖山の戦いがあります。設計は [docs/combat_realism_design.md](docs/combat_realism_design.md)（中国語）にまとめています。
- **シナリオ**：本編は四章（海口／旧帳／綱首／南海）。105の物語シーンが章の関門となり、章の合間は自由な交易を楽しめます。終盤には四つのエンディングがあります。
- **セーブとカットシーン**：セーブ枠は3つ（壊れたセーブは `.bak` のバックアップに戻ります）。オープニング、章の切り替え、エンディングには字幕付きの映画風カットシーンがあります。

## 起動方法

[Godot 4.6](https://godotengine.org/) が必要です（標準版で大丈夫です。GDScript のみで、サードパーティのプラグインは使っていません）。

1. このリポジトリをクローンします。
2. Godot 4.6 で `project.godot` を開き、F5 で実行します（メインシーンは `scenes/Main.tscn`）。

コマンドラインからは次のとおりです。

```bash
godot --path .
```

GPU のない Linux 環境では互換レンダラーを使ってください：`godot --path . --rendering-method gl_compatibility`（`.cursor/run-game.sh` は GPU のない仮想マシン向けの起動スクリプトの例です）。画面が真っ黒になったり、テクスチャが灰色の×印になったりする場合は、`.godot/` のインポートキャッシュが Godot のバージョンと合っていない可能性が高いので、`.godot/` を削除して `godot --headless --import --path .` で作り直してください。

海戦の操作：**W/S** 帆の調整、**A/D** 舵、**J/K** 左舷／右舷の射撃、**G** 接舷、**B/Esc** 離脱。

## 自動チェック

変更は、必須の36のゲートがすべて通って完了です。各ゲートが何を確認し、失敗時にどう見えるかは [docs/GATES.md](docs/GATES.md)、コマンドの完全な一覧は [docs/开发笔记.md](docs/开发笔记.md) にあります（いずれも中国語）。

Python のチェックには Godot は不要です（Python 3 の標準ライブラリのみ）。

```bash
python3 tools/check_symbols.py      # ファイル間のシンボル、autoload の順序、文面の規則、各機能の契約
python3 tools/verify_economy.py     # データの整合性、裁定取引、売り崩し、季節風、請負などの経済ルール
python3 tools/simulate_run.py       # 一局を最後まで自動で通し、行き詰まりや帳簿のあふれを探す
python3 tools/verify_story_data.py  # シナリオの効果キーとセーブ項目
python3 tools/check_probe_registry.py  # すべてのプローブが登録されているか
```

Godot のチェック（先に一度アセットをインポートします）：

```bash
godot --headless --import --path .
godot --headless --path . -s res://tools/godot_smoke.gd          # スモークテスト。最終行が GODOT SMOKE PASS
godot --headless --path . -s res://tools/godot_compile_check.gd  # 全スクリプトのコンパイル
godot --headless --path . -s res://tools/godot_story_check.gd    # 本編の流れとセーブの往復
```

`tools/` には、海図、経済パネル、セーブ、カットシーン、海戦、キーボードフォーカス、効果音などを確認する `qa_*_probe.gd` が170本以上あります。どれも `godot --headless --path . -s res://tools/<プローブ>.gd` で実行できます。

## ディレクトリ構成

```
data/      港、商品、船、人物、章、物語シーン、カットシーン、エンディングなどの JSON データ
scenes/    シーン（メイン、海図、海戦、カットシーン、UI）
scripts/   GDScript。core/ は autoload のシングルトン（Calendar、Economy、Fleet、Crew、Voyage、SaveLoad）
assets/    アート、フォント、シェーダー、船のメッシュ、海図の下絵
tools/     Python の静的チェック、Godot のスモークテストとランタイムプローブ、アートと船のパイプライン
docs/      設計文書、史料調査、監査記録、ゲートの説明（目次は docs/README.md）
```

## コントリビュート

Issue や Pull Request を歓迎します。特に史実の考証、文章、バランス調整、バグ報告は助かります。

- 提出前に上記のチェックを実行してください。少なくとも変更した箇所に対応するゲートは通してください（[docs/GATES.md](docs/GATES.md) を参照）。
- スクリプトや素材を追加するときは、Godot が生成する `.uid` / `.import` ファイルも一緒にコミットしてください（`tools/check_sidecars.py` が確認します）。
- `docs/` に文書を追加したら、[docs/README.md](docs/README.md) に一行追記してください。
- 経済バランスは繊細です。数値の根拠は [docs/复刻设计_大航海时代标准.md](docs/复刻设计_大航海时代标准.md) にあります。
