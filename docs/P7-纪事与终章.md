# P7 纪事与终章

> 状态：**已实现。** 三套校验在无 Godot 的环境下通过。博多、流求的场景 id 与港口 id 相同：剧情选项仍播正文；`docked` 为真（靠岸之后）才打开港口界面，行会因此进得去。
> 基线：`993edc1`（`main`）。脚本 5490 行（2026-09-23 对 `scripts/**/*.gd` 计数）。三套校验是验收门槛，本机仍无 Godot。
> 上一份总设计 `docs/复刻设计_大航海时代标准.md` 的 §8.7 仍写着 P2/P4 未做，那是过时的。以本文和 README「进度」为准。

## 这是什么

P0–P6 已经是一套能跑通的大航海沙盒：行情、舱位、季风、舰队、海战、职事、章节闸门都在。玩家从 98 个场景里那条还通着的序章走到泉州，之后游戏只剩经营。

纪事层是夹在序章和沙盒中间的那本账。它让序章里已经写下的选择进入港口里的世界，并在第四章给出一个由玩家亲手合上的结局。它不重写剧情，也不再加一套物价。

类比：船和货是已经造好的船；这一阶段是把航海日志接到港上的人，并写上最后一页。

## 为什么是这一份

原路线写到 P6 为止。P6 自己的收尾句是「旗标与剧情场景的联动、结局条件」，至今没做。声望投资在总设计的差距表里仍是空的，但名声若直接改物价，会和已经锁死的杂事（抽解 ×0.64）叠在一起，把 §8.2 的套利账本打穿。所以声望要有出口，出口不能是价格。

下一份重型任务就是把这三件做成一个系统：效果进账、名声与商誉有一处可验证的用处、第四章可以合上。

明确排到后面、不塞进 P7 的：

- 士气哗变（总设计 §4.5 提过，触发链是另一套）
- 海上相逢时真的买卖（现在只是一句行情闲话）
- 把 47 个无入边场景接回主线
- 新的 autoload `Chronicle`。状态已经在 `GameState` 里，`SaveLoad` 整份序列化它。再拆一个单例只会多一条存档路径

## 子系统一：效果进账

改 `Main.apply_effects`，并给 `GameState` 加对应字段。序章场景正文不动。

| 键 | 行为 |
|---|---|
| `network` | 整数相加，钳在 **-100～200** |
| `merchant_credit` | 整数相加，可负，同样钳在 **-100～200** |
| `ledger_note` | 字符串 id 追加进 `ledger`，重复的不二次追加 |
| `sea_tendency` / `scholar_tendency` | 整数相加，钳在 **0～20** |
| `discovery` | 用发现物的 `name` 精确对应到 `id`，再走现有 `record_discovery`。对不上是校验失败，不是静默跳过 |
| `supplies` / `cargo` / `ship` / `cargo_loss` | 追加账册条 `ignored:<键名>`，**不**调用 `Fleet` |
| `money` / `days` / `flag` / `chapter` | 维持现状 |
| `fame` | 改走 `GameState.add_fame`。负值允许从剧情扣，但结果不低于 0 |

`report_discovery` 和海战胜利（`SeaChart` 里现在直接 `fame += 3`）也改走 `add_fame`，避免两套加法。

沙盒里另外三处会改商誉，使「接了那封无押信」（商誉 -8）不至于永久被行会拒之门外：

| 事件 | 商誉 |
|---|---|
| 市舶司成功上报一件发现 | +1 |
| 章节晋升成功 | +3 |
| 出港被查扣（`customs_inspection` 里 `confiscated == true`） | -4 |

不在每笔买卖上加减。商誉不是第二套金钱。

新字段进 `GameState.to_dict` / `from_dict`。缺字段的旧档按 0 或空数组读入。`SaveLoad.VERSION` 从 2 提到 **3**。

## 子系统二：声望阶与行会

### 声望阶

发现录全上报是 187 点名声，所以顶阶门槛放在 180：打完发现录就能到，不必刷海盗。

| 名声 | 称谓 | `borrow_limit` 的上限 |
|---|---|---|
| 0–39 | 散商 | 3000（即现在的 `DEBT_CEILING`） |
| 40–99 | 客纲 | 3800 |
| 100–179 | 记名 | 4600 |
| ≥180 | 簿有名 | 5400 |

只改 `GameState.borrow_limit()` 的上限那一项。`borrow` / `repay` / 月息 3% 不动。

定 5400 的理由：它高于现有 3000 的破产垫，又不超过现有上限的两倍（6000）。月息 `ceil(5400 × 0.03) = 162`。垫高的是翻身的额度，不是第二笔本金。总设计 §8.3 里泉州→博多单程净赚 11190，5400 仍低于那一趟；实现时以当时 `simulate_run.py` 印出的该趟净赚为准，断言 `5400` 小于该净赚。若那趟净赚已经低于 5400，先把顶阶上限降到净赚之下，不要去抬物价。

179 仍是记名（4600），180 才是簿有名（5400）。名声 0 时上限仍是 3000。

### 行会

现在的「行会」是占位文案。做成三座港上的同一套面板：泉州、博多、广州。澎湖、占城、南岛海道不设行会。

博多和广州没有 `type: port` 的场景，走的是通用港口设施。不要把行会塞进 `GENERIC_FACILITIES`（那会让每个小港都冒出一间行会）。在组装设施列表时，仅当港口 id 属于这三座，追加一张行会卡。

面板三件事：

1. **看账。** 称谓、名声、商誉、人脉、海路倾向 / 士人倾向、账册最近 8 条。不花时间、不花钱。
2. **入行。** 该港尚未入行，且商誉 ≥ 8，且现钱 ≥ 2000：扣 2000，商誉 +4，人脉 +2，旗标 `guild_<港口 id>`。2000 高于开局的 1000，第一天入不了行；低于第二章本钱门槛 20000。
3. **已入行**再点只显示看账，不能在同一港再交一次 2000。

入行不改行情、不改抽解、不改佣金。商誉低于 8 时按钮在，按下只说明为什么还不收，数值不动。

### 贡院

只在兴化和泉州（这两座港的设施列表里已经有 `city_exam`）。每章可坐一次，旗标 `exam_sat_ch<章节号>`。

花费 **15 日**（`GameManager.advance_days(15)`）。行情每日回归 0.045，约 15 日回复一半，所以赴试会错过一轮价格，这是成本，不是装饰。

- `scholar_tendency >= sea_tendency`：名声 +4，士人倾向 +2，另记旗标 `exam_sat`
- 否则：名声 +1，海路倾向 +1，不记 `exam_sat`

不发钱，不跳章，不改船。开局二选一已经把一边倾向设成 4、另一边 0，所以第一次贡院会顺着序章那个选择走。

### 住处

住处是账册和存档，不是第三套经营。正文列出：称谓、已选结局（若有）、账册全文、三个存档槽（复用现有 `SaveLoad`，不要再写一套序列化）。

泉州、兴化、占城的设施列表里已经有 `city_residence`。结局按钮放在这里，不另开场景。

### 旅店

同一只手改 `_on_facility_pressed` 时，把 `city_inn` 并进现有的四个后缀重写。点旅店应进入已经写好的 `_setup_inn`。这是接线修复，不改歇息和候风的数值。

## 子系统三：终章

新文件 `data/endings.json`。`GameManager.load_data` 读入。选定后写入 `GameState.ending_id`，再选无效。

四条结局都要求 `chapter >= 4`。前三条另要求至少上报过 **1** 件发现。默认条不要求发现，保证只经营、没勘见的档也能合上。

| id | 标题 | 在哪座港的住处可选 | 旗标（任一） | 其它 |
|---|---|---|---|---|
| `south_sea` | 南海不归 | 占城 | `chose_sea_first`、`lin_sea_route_open`、`letter_to_xinghua`、`route_charted`、`bay_surveyed`、`hakata_first` | — |
| `exam_road` | 榜上的名字还没写 | 泉州、兴化 | `chose_land_first`、`taixue_route_open`、`merchant_distance`、`exam_sat` | — |
| `temple_post` | 寺门后的短札 | 泉州 | `temple_letter`、`temple_route`、`japan_temple_network`、`stele_quest`、`stele_found` | 人脉 ≥ 10 |
| `ledger_open` | 账还开着 | 泉州 | （无） | 默认条 |

`merchant_caution` 不进任何一条。它在可达图上被两个相反的选择共用：推辞赴试，以及林阿舶把信写成湿货。用它当士人旗标会把海商线判进科举。

`chen_line_open` 也不进科举条。那一句选择的正文是答应留意海路。

多条同时可走时全部列出，包括默认条。选定之后：

- 港口状态栏与海图状态栏都在章名下显示结局标题
- 住处不再提供结局按钮
- 港口、买卖、航行保持原样。合上的是纪事，不是把沙盒关掉
- `try_advance_chapter` 在第四章本来就不会再进，不必另加锁

正文各写一段，语气接现有第二章收束（夜船、账房、寺门），不新造人物。史实年份写进正文，不写进门槛：陈子龙是咸淳四年（1268）唱第后由度宗改名文龙；1276 前后兴化城破。这些话可以出现在 `exam_road` 和年节旁白里，玩家不需要把日历走到那一年。

### 年节旁白

`advance_days` 在月份翻页、且年份进入 **1268** 或 **1276** 时各发一次 `monthly_notice`，旗标 `heard_1268` / `heard_1276` 防止重复。纯文字。不改章节、不改钱、不改结局资格。

- 每条 `any_flags` 里的旗标都能在可达场景的效果里找到（`exam_sat` 除外，它由贡院写入，校验改为断言 `Main.gd` 会 `set_flag("exam_sat")`）

## 验收时玩家能看见的变化

- 序章里选了海路或科举，泉州住处的账上倾向不同

- 商誉够了，可以在泉州花 2000 入行；物价与抽解和入行前相同
