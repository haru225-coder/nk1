# 03　开元寺双塔

- **所属港口 / 城区**：泉州（`quanzhou`） / 开元寺双塔（`qz_kaiyuan`）
- **数据来源**：既有 7 条互动，全部入热区。
- **年代与时辰**：南宋末。辰时。塔身还带着夜里的凉。西塔仁寿、东塔镇国都是新石砌的八角五层，石缝里留着凿痕。
- **画面定调**：两座新石塔夹着寺院，殿西古桑的枝伸过墙头，有人在扫地。

## 0. 玩家怎么玩

进寺院先看见双塔、古桑和殿前的香，不自动出介绍。  
墨点落在经案、西廊灯、香柜、寺前书摊、施茶的桶、浴佛的香汤，以及可登的塔。  
请经、请印本要确认。抄经、上香、施茶、浴佛花钱的，也确认。登塔是选择：东或西，现成单条确认不够，要两路。  
印本经未得 `qz_bang_print` 时可以点书摊，只说明还没到那一步。浴佛不是四月则点开说还不是这个月的事。

## 入口与过渡

### 港口页上的处标

- **图标画面**：两座细长八角石塔并立，中间露出一角屋脊和桑枝。
- **生图提示词（中）**：正方形小图标，南宋泉州开元寺双塔远影，八角五层石塔一东一西，中间一角殿脊与桑枝，焦墨细线，浅宣纸底，石青薄染，无文字。
- **生图提示词（英）**：square icon, twin octagonal five-storey stone pagodas of Kaiyuan Temple in Quanzhou, a roof corner and mulberry branch between them, ink on rice paper, no text.
- **常态**：两塔细影。
- **悬停**：塔檐一线泥金，像有风过；名称「开元寺双塔」。
- **小动作**：东塔方向一只鸟飞过塔尖，三秒内结束，不循环飞旋。

### 点进去

- **转场**：镜头从山门里看，穿过庭院推向双塔。香烟横过镜头一次，像一幅幔被风掀起。约一秒六。
- **声音**：扫帚扫石、远处一声磬，鸟从塔上扑下去。
- **进场头两秒**：小沙弥从东塔底下走过，衣摆带起一点尘。桑叶动一下。没有人向玩家合十打招呼。墨点后出。
- **短讯规则**：点开之前无字。不要先写双塔的沿革。

## 1. 画面结构

| 层 | 内容 | 规则 |
|---|---|---|
| 远 | 东塔镇国、西塔仁寿，新石，八角五层，石缝凿痕可见。天空浅。 | 右上天空留空。 |
| 中 | 殿脊、古桑伸出墙头、院里石地、香柜、西廊。 | 塔要能辨东西：东塔偏画面中右、西塔偏中左，但热区仍避开最右三成。 |
| 近 | 西廊抄经的灯和卷；殿前香柜；茶桶；四月才明显的香汤盆；寺前书摊在近景一侧。 | 人不看镜头。 |
| 热区 / 短讯 / 顶栏 | 同试点 | 短讯在右。 |

东西塔的位置：西塔（仁寿）在画面偏左，东塔（镇国）在中景偏右，但不要顶到右缘。登塔用一个热区放在两塔之间的石地，点开后再选东或西，避免两个塔各绑一条不存在的独立 id。

## 4. 各热区细致交互

### `qz_kaiyuan_sutra`　请经卷

- **闲时微动**：卷边被风掀起，又被镇纸压回。
- **悬停**：对象名「经卷」。
- **点开**：知客（声音从廊里来）：「纸是寺里抄的。」　他不讲经义。
- **确认条**：「请经卷」。价略高于市。
- **办完之后**：案上少两卷，僧人把新抄的空白卷补上，墨线还没写。原句上屏。
- **再来**：仍可买。卷的包袱皮换了一种布。
- **变体**：辰时灯还亮着；正午把灯熄了，只剩窗光。

### `qz_kaiyuan_copy`　抄一卷

- **闲时微动**：灯焰很小，偶尔跳一下。
- **悬停**：对象名「西廊灯」。
- **点开**：旁白：西廊尽头有空席。不是拿去卖的那种抄法。
- **确认条**：「抄一卷　40钱」。一年一次。
- **办完之后**：席上多一卷未干的墨，你不能立刻卷走。小沙弥过来添了一回灯油。原效果记札记「开元寺抄过一卷经。」
- **再来**：年内再点，灯还在，席上没有空卷。只回看。
- **变体**：雨天廊外有水声，灯更稳；若学者倾向已高，知客会把笔洗往你这边推一推，仍不讲话。

### `qz_kaiyuan_towers`　登塔

- **闲时微动**：东塔窗里偶尔有人影一闪。
- **悬停**：对象名「双塔」。
- **点开**：旁白：东塔望港，西塔望城。短讯下两条：「登东塔」「登西塔」。不另收钱。
- **确认条**：不用单条确认，直接两路。选过以后今年不能再选。
- **办完之后（东）**：可用短切：塔窗看出去，桅杆一层压着一层。原句：「东塔上看见港里的帆，桅杆一层压着一层。」记「登过镇国塔。」
- **办完之后（西）**：屋瓦和殿脊。原句：「西塔上看见城中的瓦，开元寺的殿脊在脚下。」记「登过仁寿塔。」
- **回来场景**：人已经在塔下。所选那座塔的窗开着一扇，另一扇仍关。
- **再来**：年内点开只回看当时那句，两条路不再出现。
- **变体**：雾天东塔看帆只看见影；城破那年（若兴化线战况不直接改泉州塔，则不要乱加烽火）仍只看帆和瓦，不在这里写国事。

### `qz_kaiyuan_incense`　上香

- **闲时微动**：柜缝里一线烟，有时断。
- **悬停**：对象名「香柜」。
- **点开**：旁白：香钱投进去，听得到里面碰到别的钱。
- **确认条**：「上香　10钱」。每月一次。
- **办完之后**：知客在簿上添一笔（画面不要出现可认的名字）。烟密了一小会儿。原效果人情加 1。
- **再来**：本月再点，柜还在，他不接钱。
- **变体**：风大时烟贴着地走；浴佛日（四月）香柜边上人多，投钱要等一等，数据仍一次。

### `qz_kaiyuan_print`　请印本经

- **闲时微动**：摊主用布擦封面的灰。
- **悬停**：对象名「书摊」。
- **点开（无 flag）**：旁白：摊上是写本。印本这一摞空着。原句「还没到那一步」。（flag 来自贡院榜墙相关，不在本场景解释来历。）
- **点开（有 flag）**：摊主：「这个比市上让一些。」
- **确认条**：有。买后摊上少两卷。
- **再来**：仍可买。空位会再被补上。
- **变体**：辰时摊刚支开，布还没完全揭。

### `qz_kaiyuan_tea`　施茶

- **闲时微动**：碗边有没擦干的水。
- **悬停**：对象名「茶桶」。
- **点开**：小沙弥：「过客也有一份。」他说话很快，像背过。
- **确认条**：「施茶　20钱」。每月一次。
- **办完之后**：他给僧人舀一碗，再给过路人舀一碗。桶里的水位明显下降。原效果人情与人脉各加 1。可让小沙弥形象靠近 `kaiyuan_novice`，知客或学僧可靠近净海（`monk_jinghai`），短讯里不必报名。
- **再来**：本月桶还在，碗扣着。
- **变体**：热天有人自己来添水；冷天茶面上有一层气。

### `qz_kaiyuan_buddha`　浴佛

- **闲时微动**：四月盆里漂着两三片花；其他月份盆可收起，墨点仍留在原位。
- **悬停**：对象名「香汤」。
- **点开（非四月）**：「还不是这个月的事。」盆不在，地上只有一块湿痕。
- **点开（四月）**：旁白：僧人与香客排到双塔下。不写盛大法会的排场。
- **确认条**：「浴佛　15钱」。每年一次。
- **办完之后**：你伸手的位置水动了一下。原札记「开元寺浴佛日添过香汤。」人情、名声各加 1。
- **再来**：当年再点只回看。队伍已经散了，盆还在。
- **变体**：只在四月出现花瓣和队伍，避免全年都像节日。

## 5. 环境声与环境动态

- **声音**：扫石、磬（间隔长）、塔上风、偶尔的鸦。施茶后多一声舀水。不要梵唱循环。
- **动态**：桑叶；小沙弥定时走过；香烟。登塔回来后，所选塔窗开着。

## 6. 小事件与通往别处

1. **桑葚掉在石地上**（若在春夏进场，只掉一颗）：无字。点到附近无热区，可忽略。让院子像在过自己的日子。
2. **抄完经的那天**：西廊灯会多燃一会儿，即使短讯已经关掉。下次进场灯恢复原样。

通往别处：印本经依赖贡院榜墙（`qz_bang`）的 flag，本塔院不解释科举。东塔望港，和后渚、城外的船有视线关系，但不跳转码头。

## 7. 实现备注

- **可复用**：七 id 覆盖完全；买卖与人情确认条；月份、flag 的原盖章。
- **必须改**：进场无自动短讯、无整段描述。
- **新能力**：`choice` 双按钮；登塔后短切一帧窗外（可选，没有就只用文字原句）；四月香汤盆的显隐是图层；书摊在 flag 前后换货。现视图只画圆点，道具显隐要另接。
- **人物**：净海、小沙弥、普济都与开元寺有关，本场景不必强行见面，避免无数据的对话。
