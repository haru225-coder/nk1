# 41　磁灶窑

- **所属港口 / 城区**：泉州（`quanzhou`） / 磁灶窑（`qz_kiln`）
- **数据来源**：既有 8 条，热区已接线。本稿只补场景稿，照抄现行坐标，不新增互动，不改 json，不改图。
- **年代与时辰**：南宋末。午前后。坡上龙窑在烧，窑口有热。
- **画面定调**：龙窑顺坡上去，近处是出窑的青釉与粗瓷、木轮车和窑渣，不是青花作坊，也不是铁轨窑车。

## 0. 玩家怎么玩

进场先看见坡和窑口，不自动出介绍。  
收一窑瓷、领窑凭、整窑搬走、听广州，四件走原互动。龙窑坡、窑口、窑渣、窑车是观察。  
无窑凭时整窑搬走锁在「未有公凭」。听广州只改广州青白瓷行情，不表示这窑在烧青白或青花。

## 入口与过渡

### 港口页上的处标

- **图标画面**：一截龙窑窑口，旁边叠着两只青釉粗碗。
- **常态**：窑口静着。
- **悬停**：名称「磁灶窑」。
- **小动作**：窑口里亮一下又暗下去。

### 点进去

- **转场**：沿坡走几步，热气扑到脸上。约一秒二。
- **声音**：窑火低响、砖碰砖、车轮碾土。
- **进场头两秒**：窑工把一摞粗碗搬上木轮车，绳还没绑。墨点后出。
- **短讯规则**：点开之前无字。

## 1. 画面结构

## 4. 各热区细致交互

### `qz_kiln_small`　收一窑瓷

- **闲时微动**：有人把最上面一只碗摆正。
- **悬停**：「粗瓷」。
- **点开**：旁白：窑口的福建瓷按出窑的价。确认条后成交。
- **再来**：仍可买。
- **变体**：无。

### `qz_kiln_licence`　领窑凭

- **闲时微动**：窑头把纸折好又展开。
- **悬停**：「窑头」。
- **点开**：旁白：窑头给了一张凭。有它，才许整窑地搬。确认 200 钱。商誉加 1。
- **再来**：已经办过。
- **变体**：领过之后再点整窑搬走，才开得了更低的价。

### `qz_kiln_bulk`　整窑搬走

- **闲时微动**：绑瓷的绳被抽紧一下。
- **悬停**：「整窑」。
- **点开**：无凭时锁「未有公凭」，不嘲讽。有凭则确认：凭在手里，这一窑按更低的价出。
- **再来**：仍可买。
- **变体**：价只走 `price_mul` 0.8，不另叠让价。

### `qz_kiln_rumor`　听广州

- **确认 18 钱后**：窑工说，广州城等着青白瓷，景德镇来的瓷船遇风折回，牙行只好抬价收。
- **再来**：已闻。过 50 日可再听。
- **变体**：这话改的是广州青白瓷行情，不是本窑的货色。短讯不要说磁灶在烧青花。

### 观察

- **龙窑坡**：旁白：龙窑顺着坡起伏，砖缝里还嵌着捏砖时压出的指痕，一摞砖口和下一摞对不齐。再点：缺口朝下，卡在砖眉缝里。
- **窑口**：旁白：窑口内侧挂着一道烧得鼓起的釉，木框被热烘得泛白翘起。再点：透气的洞里还卡着半截断裂的棒。
- **窑渣**：旁白：窑渣和破片散在地上，大的渣块边缘缺了几口，小的瓷片上沾着没干透的土。再点：踩上去咔嚓便碎。
- **窑车**：旁白：木轮车斜停在坡边，低的一边轮子陷进土里，绑瓷的绳还绷着。再点：车板一角塌了，瓷盘叠得不正。这是木轮板车，不要写成铁轨上的近代窑车。

## 5. 环境声与环境动态

窑火、砖、车轮碾土。坡上偶尔掉一块碎砖。不要配乐盖过窑声。

## 6. 小事件与通往别处

1. **车上的瓷盘晃一下**：不要另设热区，点到仍是窑车或整窑搬走。
2. **听广州之后**：只改广州港青白瓷价，不切港，也不打开香料牙巷。

通往别处：瓷「还没进城」，城里牙行是去处，不跳转。窑凭只在本区用。景德镇作地名可用【确】。
