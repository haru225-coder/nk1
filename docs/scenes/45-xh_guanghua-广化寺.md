# 45　广化寺

- **所属港口 / 城区**：兴化（`xinghua`） / 广化寺（`xh_guanghua`）
- **数据来源**：既有 8 条，热区已接线。本稿只补场景稿，照抄现行坐标，不新增互动，不改 json，不改图。
- **年代与时辰**：南宋末。午前。南山寺里抄经，不卖经。
- **画面定调**：寺前石碑、月台香炉、殿门和石阶。碑与殿不要写出可认的字。不要写成天后宫，也不要写成清以后的庙貌。

## 0. 玩家怎么玩

城门不开时全区进不去，锁句：「城门不开，去不得南山。」区级 `unlock.war_not`：`besieged`、`closed`。  
进得去时，先看见寺和碑，不自动出介绍。  
摩碑、抄经、僧房，三件走原互动。古树、佛殿、香炉、石阶、小路是观察。  
僧房只在 1276–1277 且能进寺时出现，两条可点的路。不要给抄经、摩碑再加一套战况门。

## 入口与过渡

### 港口页上的处标

- **图标画面**：寺前一方石碑，后头是殿门一角。
- **常态**：碑立着。
- **悬停**：名称「广化寺」。
- **小动作**：碑面上过一道浅光。

### 点进去

- **转场**：沿田路走上石阶，寺门在前。约一秒二。
- **声音**：阶石、风过树叶、远处一声磬。
- **进场头两秒**：有人在廊下抄卷，笔尖停一下又写。墨点后出。
- **短讯规则**：点开之前无字。

## 4. 各热区细致交互

### `xh_guanghua_rub`　摩碑

- **闲时微动**：有人伸手在碑面上停一下，没有拓。
- **悬停**：「石碑」。
- **点开**：免费。寺前这方碑，面被摸得很亮。你按了一按，没有拓纸。学者加 1，札记「广化寺石碑按过一回。」一次。新写的句子不要再用「磨得发亮」这四个字。
- **再来**：已经办过。
- **变体**：碑上无字，不要做成可认的看点。

### `xh_guanghua_copy`　抄经

- **闲时微动**：他吹开纸上一点墨屑。
- **悬停**：「抄经」。
- **点开**：确认 20 钱。东廊下借了经，抄了一卷带走。不是市上的货。学者加 2，札记「南山抄了一卷经。」每年一次。
- **再来**：本年已经办过。
- **变体**：不要写成开元寺请印本，也不要搬净慧寺盂兰盆。

### `xh_guanghua_shelter`　僧房

- **闲时微动**：偏殿门开一条缝，里面有人走过。
- **悬停**：「僧房」。
- **点开**：年份未到或时节已过则走原锁句。景炎年则旁白：寺里腾出两间僧房。城里的人往山上走。两路：
  - 「收留」：你让妇孺住进僧房。寺里的米少了一筐。扣米 4，乡土加 2，名声加 1。
  - 「只留香火　10钱」：你添了香火，人没有留下。学者加 1。
- **再来**：已经办过。
- **变体**：围城时人根本进不了寺，不必再给这枝加一道战况门。城破与未破不要做成道德课。收留是游戏设定【设定】。

### 观察

- **古树**：旁白：阶左的古树，树根侧被台阶磕出一条浅槽，截面还湿着木屑。再点：树干结了几块硬结，剥开一角露出更浅的皮。
- **佛殿**：旁白：殿门扇板中间的木扣松动，推开时两块板之间露出一道暗缝。再点：门槛漆面被踩薄了，露出底下木色，缝里还卡着一枚拇指大小的石子。
- **香炉**：旁白：月台上的香炉，炉口内壁焦黑鼓起，炉沿磕出两道浅坑。再点：炉底香灰没扫，半张废纸的角翘在灰里，没有烧尽。
- **石阶**：旁白：第三级边缘缺了半寸，断面淡白松垮。再点：中段垫了一块补石，色和两边不一样，踩上去微微晃，凹槽里积着薄沙。
- **小路**：旁白：小路蜿到殿侧，一段塌成浅洼，没回填。再点：通向远田那段，长草压在车辙上，草根拽出几道斜丝。

## 5. 环境声与环境动态

阶石、风、一声磬、抄经的笔。不要梵唱铺满。

## 6. 小事件与通往别处

1. **碑和抄经的人左右并列**：点要分开。
2. **景炎年以外**：僧房热区仍在，锁原句，不隐藏。

通往别处：不跳转。莆田南山广化寺，宋以前已有寺【确】。
