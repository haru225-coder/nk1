# 53　贡院榜墙（广州）

- **所属港口 / 城区**：广州（`guangzhou`） / 贡院榜墙（`gz_bang`）
- **数据来源**：既有 8 条，热区已接线。本稿只补场景稿，照抄现行坐标，不新增互动，不改 json，不改图。
- **年代与时辰**：南宋末。贡院在城东北。门外只有榜墙与两通石碑。
- **画面定调**：城东北贡院门外，两碑在门左，墙上钉着空白榜纸，碑前有矮凳茶具，墙外有雾气。须与兴化军学对着街、温州州学门外分清。本区没有「看旧榜」，不要补陈文龙旧榜。

## 0. 玩家怎么玩

进场先看见门和碑，不自动出介绍。  
看榜、看碑、帮衬寒士、施茶，四件走原互动。贡院门、屋檐、榜纸、墙下空地是观察。  
帮衬寒士留下的旗号别处并不兑现。不要搬兴化旧榜、温州墙根旧碑或州学宫助印。

## 入口与过渡

### 港口页上的处标

- **图标画面**：门洞一角，门外立着一通石碑。
- **常态**：门关着一线。
- **悬停**：名称「贡院榜墙」。
- **小动作**：碑座上有手按过的暗印。

### 点进去

- **转场**：走到城东北贡院门外，墙上的纸是空白的。约一秒二。
- **声音**：有人念榜、碗摞在一起、门外雾气里的脚步。
- **进场头两秒**：碑前有人伸手按了一下座子，茶还没撤。墨点后出。
- **短讯规则**：点开之前无字。

## 4. 各热区细致交互

### `gz_bang_look`　看榜

- **悬停**：「看榜」。
- **点开**：非科年八月至十月则锁。否则免费：榜墙下挤满看榜的人。贡院门外，有人高声念，有人默。名声加 1，学者加 1。每年一次。
- **再来**：本年已经办过。
- **变体**：1268 年脚本可能追加陈文龙那一行，此处不要再讲兴化旧榜，也不要写成军学对着街。

- **贡院门**：旁白：门洞左侧墙脚缺了一块砖，门槛上沾着几处未干的深色水渍，凳脚踩上去吧嗒晃。数据原文写「吧台晃」，是后起词，本稿按「吧嗒晃」转述，不把门洞写成酒吧柜台，也不改 json。
