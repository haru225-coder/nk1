# 二十份场景稿共用约定（写给生图和实现，不上屏）

这些约定每份正文里只点到，不重复宣讲。

## 画风

底图、过场、章节卡按光荣 90 年代日式历史油画出：厚涂，画布纹与笔触可见；暮光或巳时侧光，暖金高光；暗部用深褐、墨绿、靛蓝，暗部下限约 `#2A2418`，不要纯黑或哥特黑。取同期《大航海时代》《信长之野望》包装与场景油画的调子，物象仍要能一眼看清。时代从仓库：南宋晚期至元初，十三世纪东亚海域，不是明清。界面仍走纸墨，不改 UI 主题。

统一尺寸 16:9（建议 1920×1080）。城区热区图：可点物分在左约七成；右约三成留较空的天、水或墙，给 `DistrictHotspotView` 宽屏短讯层（右侧 260–360px）。顶上约一成少挡物，留给区名、「场景／工席名单」、「回港口」。每点对应一个轮廓清楚的物体，不要叠在同一块石或同一页纸上，中心距建议不小于约 0.06（归一化）。

统一负面：文字、字母、招牌大字、水印、签名、UI 边框、现代物品、电线、玻璃、水泥、青花瓷、明清牌坊、石狮子、辫子、满清顶戴、哥特尖拱、纯黑洞穴、血红恐怖、暗黑浓雾、照片、3D 渲染、对称海报、动漫大眼。册页与告示只画模糊墨点或空白格，不要可认读的字。

## 进场与短讯

点港口处标进场景后，头两秒只看画面、听环境声，墨点约一秒后淡入。在玩家点中某个热区之前，不弹出任何文字面板——包括区 `description`、首句旁白、`DistrictHotspotView.show_idle()` 里现成的那句「后渚是泉州出洋的码头。」悬停或键盘聚焦只出对象短名。旁白最多一句，对话最多两句。买卖、雇佣、入股、领凭、花钱的人情和要花钱的传闻，短讯下接原工席确认条，点墨点不直接成交。选择枝要两条可点的路，现成确认条不够用。

## 热区与数据

热区 `id` 能对上现有 `interactions[].id` 的，沿用原 type、价格、once、unlock、flag。试点规则仍在：热区必须覆盖该区全部可见互动，且每个热区 id 都要能查到互动，否则整区退回工席名单。季节、战况、flag 未满足的互动并不隐藏（只盖「还不是这个月的事」「还没到那一步」等原句），所以它们也要有热区。标了「新增」的是观察类，建议补 `type: look`（一句旁白，不改钱货），或让视图允许没有 Book 的 `kind: place`。

墨点六态沿用首页：normal / hover / focus / pressed / visited / selected。办完买卖不置灰，仍可再买；传闻标「已闻」可重看；once 标「已办」只回看。不新造绿勾或警告红。
