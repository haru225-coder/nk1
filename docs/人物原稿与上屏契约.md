# 人物原稿与上屏契约（Astra L1）

门禁：`tools/verify_story_data.py`「Astra L1」段。改字段、改读取入口前先改那里的分类表。

## 两份文件

| 文件 | 身份 | 上屏？ |
|---|---|---|
| `data/characters.json` | 设定集原稿（策划注、攻略、结局都可写在 `bio` / `bio_short` / `portrait_note`） | 只有下表「上屏」字段 |
| `data/characters_codex.json` | 上屏文本层（玩家视角，按可见条件分段） | 全部字段 |

## 字段分类（`characters.json` 每个字段必须归入一类，新字段未归类即失败）

- **上屏** `CHAR_ONSCREEN`：`name` `alt_names` `courtesy` `title` `origin` `personality` `look` `lines`（UI 直读或文本层缺省时回落），外加 `relations[].rel`、`meta.attr_def/trait_def` 的 `name·desc`、`meta.faction_def` 的 `name`。
- **结构** `CHAR_STRUCT`：`id` `faction` `traits` `relations` `born` `died` `tier` `chapters` `attrs` `portrait` `portrait_status` `sources` `historical`——键、数值、枚举，不作正文上屏。
- **原稿** `CHAR_DRAFT`：`bio` `bio_short` `portrait_src` `portrait_note`，以及两份文件的 `meta.note`——永不上屏。

文本层字段 `CODEX_ONSCREEN`：`bio` `short` `lines` `title` `courtesy` `alt` `look` `personality`；出现未登记字段即失败。

## 断言

1. 上屏来路上的文字不得命中 `ONSCREEN_BAN`（`CODEX_META` 策划腔 + `placeholder` / `TODO` / `WIP` / `FIXME` / `pipeline` / `LLM` / `ChatGPT` / `大模型`）。
2. 原稿整份仍不许出现六个硬工程词（`placeholder` `本作` `玩家` `士人线` `海商线` `乡土线`），防止回落时带出。
3. UI 入口（`CharacterArt` `CharacterCodex` `VisionStage` `Main` `CompanionPreview` `scripts/chars/*`）里凡是 `ch/cch/other/character.get("键")`，键只许是「上屏 / 结构」两类；`layer(ch).get` 只许读 `CODEX_ONSCREEN`；`character_meta()` 只许读三张定义表；不得出现 `"bio_short"` `"portrait_note"` `"portrait_src"`。
4. 自证：门禁每次运行都往每条上屏来路塞一个带记号的禁词，扫描必须逐条抓到；哪条来路失明即失败。
5. 读取入口锁（Astra L1b，`L1B_READERS`）：全仓 `.gd` `.py` `.tscn` `.tres`（去注释）里读人物数据分三类——`raw`（`characters.json` 路径 / `CHARACTERS_PATH` / `characters_data`）、`codex`（`characters_codex.json` / `CODEX_PATH`）、`api`（`get_character` `character_for_npc` `character_for_crew` `all_characters` `character_meta`）。文件必须登记，且实际类别与登记一字不差（多读即越权，少读即清单过宽）；开发工具 / 门禁不得被 `scripts/` `scenes/` `project.godot` 引用。
6. 上屏字段锁：运行时入口按变量追踪人物字典（`ch` `cch` `other` `character`、取数口赋值的变量、遍历 `all_characters()` 的循环变量），`.get("键")` / `["键"]` / `.键` 与取数口链式读取只许「上屏 / 结构」两类；动态键、`keys()` / `values()` / `str()` / `stringify` 整份倒出一律失败。清单外的 `scripts/` 文件拿 `ch/cch/character` 读人物专有键同样失败。门禁自带合成源码自证（越界必红、合法必绿）。
