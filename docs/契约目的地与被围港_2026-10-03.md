## 一、`_contract_destinations` 现态摘录（V0928-1①）

### 1.1 目的地候选集 —— `scripts/GameState.gd:889-901`（函数本体）

```gdscript
## 当前章节能靠岸、且把这货当紧缺货收的港口。按 id 排序，月份种子才稳定。
func _contract_destinations(port_id: String, good_id: String) -> Array:
	var dests: Array = []
	for p in GameManager.unlocked_ports():
		var pid: String = p.get("id", "")
		if pid == port_id or int(p.get("depth", 0)) <= 0:
			continue
		if Economy.get_role(pid, good_id) != "consumer":
			continue
		if not Economy.is_traded(pid, good_id):
			continue
		dests.append(pid)
	dests.sort()
	return dests
```

**排除条件全表（只此四条，均与战况无关）**：

| # | 排除 | 出处 |
|---|---|---|
| 1 | 签发港自身（`pid == port_id`） | `GameState.gd:894` |
| 2 | 水深 `depth <= 0` 的不可航港 | `GameState.gd:894`（数据上如澎湖等近岸点） |
| 3 | 对此货不是消费方（`Economy.get_role != "consumer"`） | `GameState.gd:895` → `scripts/core/Economy.gd:99`（只读 `ports.json` 的 `market` 表） |
| 4 | 此货不在该港柜上（`Economy.is_traded` 为否） | `GameState.gd:897` → `scripts/core/Economy.gd:88`（同样只读 `market` 表） |

另有前置闸门在调用链别处：能进候选的港本身须过 `GameManager.unlocked_ports()`（`GameManager.gd:384`，按章节 `unlock` 字段）。**没有一条查 `Economy.war_status` / `is_market_open` / `is_port_reachable`**——这正是「被围的港照旧会被开成委办目的地」（清单 V0928-1 行原话）的代码根因。

### 1.2 选定「权重」—— 无概率，纯确定性

`contract_offer`（`scripts/GameState.gd:908` 起）内：

```gdscript
var dests: Array = _contract_destinations(port_id, gid)     # :933
var known: Array = []
for pid in dests:
	if Voyage.is_known_route(port_id, pid):
		known.append(pid)
var pool: Array = known if not known.is_empty() else dests  # :939
var dest: String = pool[int(seed / 7.0) % pool.size()]      # :940
```

- 权重规则：**熟路优先池**——候选里有已踩过的航线就只从熟路里挑，一空则全候选等权；挑选由 `seed = _stable_hash(port_id) + year*12 + month`（`:884`）整除取模决定，同港同月玩家间必现同一单；货种由 `seed % goods_ids.size()` 定（`:930`，货物过滤见 `:918-928`：要 tradable、非违禁、基准价 ≥ 15、有料积、本港非消费方、候选非空）。
- 期限与酬金：`Voyage.plan(port, dest, RUMB)` 的静风日数 + `CONTRACT_SLACK_DAYS = 3`（`:864`）；酬金 = 目的港逐件卖价 + 基准价 × 0.12（`:863`）。**期限不含围城缓冲**（清单 B 案欲改之处）。

### 1.3 围城在别处的既有口径（对照）

- `Economy.is_market_open`（`scripts/core/Economy.gd:271-273`）：`war_status ∈ {besieged, closed}` 时牙行**闭门**——但只挡交易页，不挡委办开单的目的地池。
- `Economy.is_port_reachable`（`:276-278`）：`closed` 不可抵达——但只用于航海，开单链不查。
- 战况表（`data/ports.json` 各港 `war` 字段）逐月推进，含 besieged 的港：**兴化 / 兴化海口 1276-11**、**福州 1276-10**、**广州 1276-11**；含 closed 的：博多唐房、萨摩 1274-10（文永之役）。
- 闭门签发的兜底（V0928-1 已拍 A 案返修）：`Main.gd:1314 MARKET_SIDE_DOOR`——目的港闭门时牙行开侧门只收在身委办货，即清单「A 案」。争议在**新单**是否还会发去闭门港。
