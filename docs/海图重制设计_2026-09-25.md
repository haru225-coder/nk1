# 海图重制设计（2026-09-25）

> 状态：**架构已定，视觉细节随考究报告收口**。分支 `feat/chart-remake`（自 `align/cursor-absorb` 开出）。
> 目标：把 `SeaChart` 从「中栏一块 250px 暗色小图」重做成 2026 年水准的全屏海图 + 舆图（地形），一切地名、航线、季风、险地符合 1255–1279 年史实。
> 原则：**经济与里程一字不动**（`Voyage.distance_li` 仍是大圆，事件表不动），只换呈现层。

---

## 一、基线诊断（截图 `~/tmp/nk1-map/shots/baseline_*.png`）

| 项 | 现状 | 问题 |
|---|---|---|
| 版面 | 三栏文字面板，中栏顶部 250px 图 | 图是配角，整屏是文字 |
| 投影 | 等经纬 × cos(平均纬度)，随解锁港口自动取景 | 章节切换时整张图形变，无缩放拖拽 |
| 陆地 | 单色平涂 + 1px 描边 | 无地形、无水深、无纹理 |
| 航线 | 1px 直线 / 折线 | 无动画，船不在图上 |
| 航行 | 无事之日递归瞬间跑完 | 玩家看不到船走，只看日志刷字 |
| 标注 | 系统回落字体 6 处海名 | 无山川、无险地、无罗盘、无比例尺 |

## 二、目标形态

全屏海图为主体，信息面板压在图上（半透明绢本纸片），可收起。

```
┌──────────────────────────────────────────────────────────────┐
│ ◤宝祐三年三月初一  东北季风·强◢           罗盘(二十四向)  ⧉舆图/海图 │  ← 顶栏（CanvasLayer）
│                                                              │
│   ┌状态卡┐            [ 海 图 全 屏 ]              ┌日志卡┐   │
│   │舰队  │   陆地晕渲·水深分层·墨线岸·季风流线      │航海  │   │
│   │水粮  │   港口朱砂标·航线·船标沿线逐日移动        │日志  │   │
│   └──────┘                                        └──────┘   │
│                                                              │
│ ┌────────────────────────────────────────────────────────┐   │
│ │ 针路│外洋│傍岸 ‖ 目的地：温州 697里 方位29° 顺风 … ‖ 发 舶 │   │  ← 底栏（抽屉）
│ └────────────────────────────────────────────────────────┘   │
```

- **海图模式**（默认）：石青/石绿分层水深为主角，陆地淡赭压低；港口、航线、季风流线、险地清晰。
- **舆图模式**（切换）：陆地晕渲分层设色为主角（山脉、河流、城池），海压淡；供看地形与山川。
- 两模式共用同一底图纹理，着色器按 `mode` 参数混合，不加载第二张大图。

## 三、坐标与数据

### 3.1 投影
等距圆锥，标准纬线 15°N / 35°N，中央经线 120°E（`data/chart_projection.json`）。
- Python `tools/build_terrain.py` 与 GDScript `scripts/chart/ChartProjection.gd` 同一公式，已做六点一致性验证（像素坐标逐位相同，反算零误差）。
- 选它不选墨卡托：1°N–49°N 跨度下墨卡托把高丽/九州放大 1.4 倍；不选等经纬：北端形状压扁 0.72。圆锥在全域形状与面积都接近真实，且纬线微弯、经线收敛，本身就有「图」的气质。

### 3.2 底图（离线生成，入库 `assets/map/`）
| 文件 | 尺寸 | 内容 |
|---|---|---|
| `terrain_4096.png` | 4096×4318 | 舆图底色：分层设色 + 双光源晕渲 + 水深分层 + 近岸浅水晕 + 岸内墨晕 |
| `mapdata_4096.png` | 同上 | 着色器数据：R 陆地高度 / G 海深 / B 离岸距离(海侧) / A 陆地掩膜 |
| `data/chart_projection.json` | — | 投影参数 + 画布像素映射 |

数据源：ETOPO 2022（NOAA，公有领域）高程；Natural Earth 1:10m（公有领域）陆地/小岛做岸线掩膜（岸线用矢量而非高程 0 米线，保证锐利）。画布经纬框 104–136°E / 6–40°N，比港口范围宽一圈；像素约 0.9 km。

### 3.3 矢量层（运行时按投影绘制）
- `data/coastline.json`：现有 Natural Earth 环（386 环 12936 点），画墨线岸。
- `data/sealanes.json`：绕岸折线（考究后按史载针路替换航点）。
- `data/chart_labels.json`：海名/岛名/山川/险地标注（考究后重写，加 `kind` 与显示层级）。
- `data/ports.json`：港口（考究后校正名字与泊地坐标；`lat/lon` 一改里程就变，改坐标必须重跑 verify_economy / simulate_run）。

## 四、场景架构（Godot 4.6）

```
SeaChart (Control, scripts/SeaChart.gd —— 航行逻辑不动，只换 UI 构建)
├─ MapContainer (SubViewportContainer, full rect, stretch)
│  └─ MapViewport (SubViewport)
│     └─ MapWorld (Node2D, scripts/chart/MapView.gd)
│        ├─ Terrain (Sprite2D, terrain_4096 + ChartTerrain.gdshader)
│        ├─ CoastInk (Node2D _draw：岸线墨线、计里画方)
│        ├─ Flow (Node2D _draw：季风/洋流流线，逐帧推进相位)
│        ├─ Lanes (Node2D _draw：熟路淡线、生路虚线)
│        ├─ Route (Node2D _draw：当前航段，顺风绿/逆风朱)
│        ├─ Ports (Node2D _draw：朱砂标 + 名字，按缩放层级显隐)
│        ├─ Labels (Node2D _draw：海名/山川/险地，分远中近三档)
│        ├─ Ship (Sprite2D，ship_topdown.png，沿航线逐日 tween)
│        └─ Camera2D (缩放 0.35–4.0，拖拽惯性，取景 tween，边界钳制)
├─ Hud (CanvasLayer)
│  ├─ TopBar   日期 · 季风 · 罗盘 · 舆图/海图切换 · 面板开关
│  ├─ StatusCard(左) 舰队/水粮/委办
│  ├─ LogCard(右)   航海日志
│  ├─ BottomDrawer  航法三钮 · 目的地列表 · 航段详情 · 发舶/回港
│  └─ Scale         比例尺（百里）
└─ EventLayer (CanvasLayer, 现有事件浮层，改绢本样式)
```

- 摄像机只在 SubViewport 内起作用，HUD 不受影响；SubViewportContainer 挂后期 shader（纸纹、晕影、四边褪色）。
- 全部自绘层在 `_draw` 里按 `camera.zoom` 反缩放线宽与字号，缩放时线不变粗。
- 岸线多边形投影结果缓存（投影不随缩放变，只算一次）；只画视窗相交的环。

## 五、交互

| 操作 | 行为 |
|---|---|
| 滚轮 / 双指 | 以鼠标为中心缩放，0.35×（全域）→ 4×（港湾） |
| 拖拽 | 平移，松手带惯性，钳在底图范围内 |
| 点港口标 | 选为目的地（与列表联动），镜头平滑取景到「起点+终点」 |
| 发舶 | 底栏收起，船标沿航线逐日移动（每日 0.35 s），日期与余程随之跳；事件日弹层，船停 |
| 到港 | 船标停在港口，弹到港层 |
| 舆图/海图 | 着色器 `mode` 0↔1 半秒过渡 |
| H | 收起/展开全部面板，纯看图 |

## 六、视觉规范（依考究报告收口，2026-09-25）

- 色板（宋绢本矿物色，锚点：《梦粱录》「大洋之水碧黑如淀，有山之水碧而绿」、《千里江山图》「先赭后青绿」、《高丽图经》三洋水色）：绢底 `#E4D3AE`、墨 `#2A241D`、淡墨 `#5C5247`、朱砂 `#A8322A`、朱膘 `#D0654A`、石青深 `#1F3A52`、石青 `#35607F`、三青 `#7FA3B5`、石绿 `#4E8469`、头绿浅 `#8DB59A`、赭石 `#8C5E34`、赭浅 `#C39A6B`、金泥 `#C49A3C`、蛤粉 `#F2EBDA`。色相 ≤ 5，朱砂是唯一强调色。
- 海：按水深四档石青分层 + 海底晕渲；近岸头绿浅晕；海图模式加淡等深线。舆图模式海压向纸色。
- 陆：大青绿——赭浅平原、赭石丘陵、石绿中山、石青灰高山，双光源晕渲。海图模式陆压向绢色 36%，舆图全彩。
- 字体：霞鹜文楷（OFL；与美术线统一用 Medium 子集）。图上地名一律**繁体旧字形**（海图是宋代实物），面板 UI 仍简体。
- 港口：宋《地理图》「州府加方框」——朱砂方框、蛤粉内填；市舶司港（泉州、庆元、广州）双框；当前所在墨圈、目的地金圈；本手风不放的港淡显。远景（zoom < 0.45）只留市舶港与本手可选港。
- 罗盘：二十四向三环（内四维朱砂、中十二支墨、外八干淡墨），48 刻度（缝针短刻），中心淡青「浮针」水面；航向读法「单X针」/「XY针」（《真腊风土记》「行丁未针」）。
- 计里画方：《禹迹图》「每方折地百里」；远景千里方，中景五百里，近景百里。左上题记框「東南海道圖 · 每方折地百里」。
- 航线：熟路淡墨细线；剧情虚构的「传闻海道」（台湾北端—博多 / 耽罗）虚线；当前航段顺季风朱砂实线、逆风淡墨虚线、途中换风赭石。
- 洋流：monsoon.md C1–C12 流线，按农历月显隐；暖流金泥、寒流石青，流动虚线。黑潮文案用元人语「落漈」，不用清代「黑水沟」。
- 险地：朱砂三叠浪 + 名（七洲洋、长沙石床、三合流、三合溜、落漈、半洋焦、沙尾、急水门、黑山、夹界山）。
- 船标：矢量福船俯视剪影（原 `ship_topdown.png` 是烤死棋盘格的假透明图，不用），帆随微浪轻摆，艉部朱旗。
- 不用：西式罗盘玫瑰、海怪、外发光、经纬网、「黄海」「琉球」「黑水沟」「台风」「鸡笼/淡水」等晚出名称。
