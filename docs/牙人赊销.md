# 牙人赊销

牙人赊销是一本独立的赊销簿：把舱里货交与本港牙行，言明锁价，两月后结账。与蕃商赊贷（debt）不同，不借现钱、不生息；与委办（contract）不同，不押船、不罚款。倒账时货钱两空。

## 机制

- 卖价：`Economy.credit_sale_price(port, good, qty)` = 现卖 qty 件逐件压价的均价（`estimate_sell_revenue / qty`）乘 1.08（延后结账贴水），锁死为赊销簿的 `unit_price`；赊多了同样压价，不比现卖多占便宜。
- 牙行页：每张货卡卖钮一行末尾多一枚「赊 10」（不足 10 件按舱里可卖的件数；在身委办要的那几件不赊），悬停写锁价、到期月与倒账成数。
- 期限：`Economy.CREDIT_TERM_MONTHS` 为两月，`due_ym = year × 12 + month + 2`。
- 倒账概率：`base = max(0.02, 0.08 − merchant_credit × 0.003)`，再乘战况倍数（loyal 1.0、contested 1.5、besieged 2.5、fallen 4.0、closed 4.0）。按笔 id 定骰，读档前后同一结果。
- 结算：`GameManager.advance_days` 月初调 `GameState.settle_broker_credit`，到期赊账逐笔结清：骰中倒账写「倒账」；否则按锁价 `add_money`，写「赊账」。
- 市场：本港牙行收此货（`is_traded`）、市场开门（`is_market_open`）；卖后 `apply_sell_impact` 与现卖同口径压行情。
- 信用：海商信用越高倒账率越低；战况越坏倒账率越高。

## 存档字段

`GameState.broker_credit`：数组，每笔 `{id, port, good, qty, unit_price, due_ym}`。读档归一：坏条丢掉、id 去重、字段只留定形六格。`SaveLoad` 把 `broker_credit` 当数组体检。`GameState.to_dict` / `from_dict` 已包含。schema 仍是 4，旧档缺省为空数组。

## 平衡

贴水 8% 高于最低倒账率 2%，给高信用玩家留出净利；战时与降元港倒账率升高，赊销在那里风险大。与季节行情层（sim3）和蕃商赊贷（debt）互不相扰：不改 `price_at_rate`、不改 `debt`、不改季节倍数。
