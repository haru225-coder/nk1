# 终局系统化：不做文字游戏

> Snow 2026-09-04 拍板：序章 5 处校勘全收（已落数据）；**终局不做线性幕串**。
> 本稿把 `终局幕本_2026-09-04.md` 的 62 幕拆成系统与事件，幕本降级为**台词素材库**——每条台词只在对应系统的弹窗 / 遭遇 / 设施对话里出现一两句，不再有「…………」连点。
> 原则：沿用 `OPEN-WORLD-IDENTITY-v0.4.md`「地点 → 入口卡 → 活动 → 后果」与 `复刻设计` 的「剧情为骨、沙盒为肉」；**不新增任何独立剧情场景**，只加数据、状态和事件。

## 一、总原则：历史是天气，不是过场

1275 年十二月起，历史不再由 CG 讲，而是由**四个已有系统的参数**表现：

| 系统 | 1255–1274 | 1275–1277 |
|---|---|---|
| `Economy` 港口经济 | 正常季风套利 | 港口逐个进入 `status: besieged / fallen / loyal`；fallen 港税率 ×2、缉私 ×2、宋钱贬值；loyal 港粮价飙升、硫黄/铁器成需求品 |
| `Voyage` 航海 | 风暴、海盗 | 新增遭遇类型 **征船**（`requisition`）、**元军哨船**（`yuan_patrol`）、**难民船**（`refugee`），概率随年份递增 |
| `Combat` 海战 | 海盗 | 复用为 **囊山伏击**（陆战皮肤）与 **崖山外围**（海战，敌方铁索连船 = 我方机动优势） |
| 酒馆 / 设施对话 | 新闻轮播 | 新闻表 `news.json`（幕本 §〇 18 条）；设施出现「征召 / 借船 / 站队」入口卡 |

玩家永远在地图上、在港口里、在船上。没有黑幕独白。

## 三、1268 分岔：一次结算，不是一段剧情

`Calendar` 到 1268-04 触发**结算弹窗**（与章节晋升弹窗同一 UI）：

- 条件 `scholar_tendency ≥ sea_tendency` 且 `taixue_admitted` → `player_name = 陈文龙`，`identity = scholar`，弹窗一行：「唱第日，御笔易名。」 + 士人线解锁：福州「官府」入口卡出现「朝报 / 奏疏」功能（消耗时间换 fame）。
- 否则 → `identity = merchant`（或 `hometown` 若乡土最高），弹窗一行：「今年殿试，兴化无人登第。」 + 市舶司册子上「纲首」头衔正式可用（第三章条件之一）。

弹窗只有一个「知道了」按钮。后果在世界里体现：士人线后续每年收到朝廷短札（可点可不点，点了 +fame −time）；海商线永远不再收到。

## 四、1275.12「出国门而悔」：一次航线选择

不做三幕对话。`identity = scholar` 且 Calendar 到 1275-12：地图上玩家被移到**临安**节点，只有三条可点航线，航线卡上写后果：

| 航线 | 卡面 | 效果 |
|---|---|---|
| 临安（原地，等待 7 日） | 「再上一疏」 | 时间 −7 日，`petitioned_return`，之后自动海路回兴化 |
| 临安 → 明州 → 温州 → 兴化 | 「走海路回家」 | 正常航行（可遇风暴/征船），`no_official_title` |
| 临安 → 泉州 | 「去找林阿舶」 | 到港触发**清算活动**（县学籍册 / 举荐信 / 宗祠担保三张卡，每张要付钱或 fame 才能撕），完成后 `identity = merchant`，保留 `renamed_wenlong` |

这就是 v0.4 讲的「地图方向即命运方向」——北回头、南下海，用航线选，不用按钮选。

## 五、甲 · 忠肃 → 「守城模式」（复用海战 + 设施）

1276-05 起，兴化港的入口卡换皮：

| 入口卡 | 原功能 | 守城期功能 |
|---|---|---|
| 衙门 | 验引 | **募兵**（钱→兵；上限受 fame）；**编石手军**（一次性事件：留 / 遣，影响囊山伏击数值） |
| 市场 | 买卖 | **屯粮**（粮价随月暴涨；粮 = 守城回合数） |
| 酒馆 | 新闻/雇人 | **使者事件**：王刚中使者、姻家使者两次弹窗，各三选一（斩 / 放 / 收），改 fame、hometown_trust、士气 |
| 船厂 | 修船 | **城防**（把修船预算换成城墙耐久） |
| 码头 | 出海 | **家人**：母亲与幼子在 1276-11 被扣福州；此后码头卡上常驻一行「福州尼寺」，点开只有一句台词，不可操作——**玩家什么都做不了，这就是设计** |

**囊山伏击**：1276-12 元军来袭 → 进入 `Combat`，我方战力 = 兵 × 士气 × (石手军 ? 1.5 : 1)，地形固定我方先手两轮。赢 → 元军退，士气 +；输 → 粮 −30%。最多三轮。

**林华事件**：第三轮前，酒馆弹出「部将请出侦」。若 `crew_history` 含 `lin_hua`，多一个「提醒他缆绳」选项——**史实不变，他仍然降**，但玩家多得 5 士气（城里人看到你认人）。这是「知道历史也改不了历史」的最小表达。

**城破**：粮归零 或 三轮后必破。不弹 CG——地图上兴化节点变灰，标签「fallen」，玩家角色移到「杭州」节点，只剩一张入口卡「岳王庙」。点开：一句「此皆节义文章也，可相逼邪？」，然后《诗寄仲子》八句作为**结算画面背景文字**（和章节晋升同一 UI），结束。母亲那句放在结算画面最后一行小字。

全程玩家在做的事是：花钱、屯粮、招兵、打三场仗、做两次三选一。没有一幕是「点下一句」。

## 六、乙 · 纲首 → 「站队事件 + 港口状态」

1276-05 泉州 `war_status = contested`：

- 市舶司入口卡出现「征船名册」：玩家船只被标记，三选一（借张 / 跟蒲 / 出港）。**这是一张卡，不是一幕对话。**
- 借张：船队 30% 编入宋军，不可用至 1276-11；fame ↑，`merchant_credit` ↓；泉州蒲氏关注度归零（他们不管你了）。
- 跟蒲：`merchant_credit` ↑，泉州税率永久 −20%；fame ↓；张世杰船队出港时会「误击」你在港外的船（一次 `Combat`，可跑）。
- 出港：正常航行，五个月内不能回泉州（港口对你 `closed`）。

1276-11 泉州 `fallen`。**蒲寿庚不出场**。他的那句话作为**新闻**出现在所有港口酒馆：「泉州蒲提举告其民曰：陈瓒非不忠义，如民何。」若 `renamed_wenlong`，新闻里的名字自动替换成 `player_name`——玩家在别的港口的酒馆里，读到自己的名字被拿来讲道理。这比一幕 CG 狠得多，成本是一次字符串替换。

结局分流靠**航线**：
- 开船去广州 / 崖山节点（1279-02 可达）→ 崖山 `Combat`，敌方铁索连船（我方每回合可脱战）→ 脱战成功 = 「海上宋鬼」结算；
- 留泉州跑商到 1285 → 「泉州蒲氏的船」结算，结算画面上市舶司册子多一个蒙古官名。

## 七、丙 · 岸上的根 → 「投资 + 一次航行」

`identity = hometown`：
- 1270 年起，陈瓒在兴化「亲族宅」入口卡可**投资**玩家（船股，最高 3000 缗），是乡土线的经济来源。
- 1276-11 兴化 `fallen`，1277-02 陈瓒举兵 → 兴化短暂回 `loyal` 40 日（Calendar 驱动）。
- 40 日内，兴化码头出现一张卡「涵江海口 → 旧避风澳」：需要第一章 `must_visit: ryukyu` 已达成（不然这张卡不存在——第一章的复核在这里变现）。
- 点了 = 一次真实航行（四条船，载人不载货，可遇风暴），到达旧避风澳 = 「岸上的根」结算，结算画面背景是老夫人晒草稿那一句。
- 不点，40 日到 → 兴化再 `fallen`，玩家死亡结算（车裂那句只作小字）。
