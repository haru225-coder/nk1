# nk-1 美术规范（UI 层 · 绢本墨笔）

> 适用：Godot 4.6.3，基准 1280×720（`stretch = canvas_items`，`aspect = expand`）。
> 维护：UI 线（tools/art/）。本文件写给集成者看：怎么接主题、每个控件用什么、每张贴图干什么用。
> 效果样张：`tools/art/ThemePreview.tscn`（数字键 1–6 切页：港口 / 酒馆募人 / 弹窗 / NPC / 标题 / 控件总表）。

## 1. 两层画风

| 层 | 画法 | 要点 |
|---|---|---|
| 绘画层 | 南宋晚期厚涂油画，暖烛光 / 暮光，历史写实 | 背景 `assets/bg_*.jpg`、立绘 512×640、港口画。全部同源，不混照片、不混卡通 |
| UI 层 | 绢本墨笔：宣纸与旧绢底、焦墨描边、朱砂印、泥金点缀、靛青压底 | 不用现代扁平、不用霓虹、不用圆角胶囊；角用「委角」（切角）或回纹 |

**2× 规则**：`assets/ui/nk1/` 下所有贴图都按 2× 出（贴图像素 = 逻辑像素 × 2，边长均为偶数）。
- 九宫（面板 / 按钮 / 条）已由 `build_theme.gd` 包成 `size_override = ½` 的 `PortableCompressedTexture2D`（`assets/theme/tex/*.res`），`StyleBoxTexture` 按逻辑像素切、按 2× 纹素采样，1280×720 正好 1:1，2560×1440 / Retina 不糊。**集成者不要直接拿 PNG 去做 StyleBoxTexture**，否则角花会放大一倍。
- 直接用 PNG 的（logo、印、墨迹、画框、角花）：`TextureRect.expand_mode = EXPAND_IGNORE_SIZE`，尺寸给「像素 ÷ 2」或按需缩放；大图（logo / 墨迹 / 画框 / 印 / 角花）的 `.import` 已开 mipmaps，缩小显示时把 `texture_filter` 设成 `TEXTURE_FILTER_LINEAR_WITH_MIPMAPS`。
- 小图标（关闭、勾选、单选、下拉箭头）是 SVG → `DPITexture`（`assets/theme/tex/icon_*.tres`），随缩放重新栅格化；另有 `icons/*@2x.png` 备用。

### 对比度（实测，WCAG 相对亮度，按字的真实位置）

方法（2026-09-25 返工起）：ThemePreview 每页截三帧——正常、`--hide-text`（字透明）、`--fill-off`（只去字的填充，描边 / 墨晕照画）。字形像素 = 正常帧里与字色相近、且与无字帧差异大的像素。
- **raw**：字形 + 外扩 2px 处「无字帧」的底色 → 字直接压在底上（不计描边）；
- **eff**：字形像素处「去填充帧」的颜色 → 字下面实际垫着的东西（描边 / 墨晕 / 底）。
取 P10（最坏一成）。89 个文字控件 eff P10 全部 ≥ 4.5；完整表见 `~/tmp/nk1-art-work/reports/ui.md` 返工记录。

| 背景（样张位置） | 字色 | raw P10 | eff P10 |
|---|---|---|---|
| 深墨面板（状态栏 / 对话 / 弹窗正文） | 宣纸 `#e9dcc0` 正文 | ≥ 10.0 | ≥ 10.0 |
| 深墨面板 | 亮泥金 `#ecd08a` 抬头（HeadingLabel） | ≥ 8.8 | ≥ 12.0 |
| 深墨面板 | 旧绢 `#cdb88f`（CaptionLabel） | 8.3 | 8.7 |
| 港名墨刷底 `ink_splash_plate` 安全区 | 宣纸 TitleLabel / 旧绢 OverlayCaption | 13.9 / 9.7 | 14.7 / 10.2 |
| 直接压画面（酒馆亮木柱） | 旧绢 **OverlayCaption** | 2.7（不计描边） | **9.9** |
| 直接压画面（酒馆） | 亮泥金 HeadingLabel 32（自带描边 4） | 3.9 | 10.2 |
| 直接压画面（标题屏海图） | 宣纸 **OverlayText** 20 | 8.6 | 14.3 |
| 绢面板 | 墨 InkText / InkHeading | ≥ 7.9 / 8.5 | ≥ 7.7 / 8.5 |
| 绢面板 | InkCaption `#3d3124` | ≥ 5.9 | ≥ 5.8 |
| 宣纸卡 | 墨 InkHeading / InkCaption | ≥ 12.5 / 8.9 | ≥ 12.5 / 8.9 |

以下沿用首轮取样（空白面板区像素，非逐字）：弹窗题签（旧绢）上墨字 6.4；墨底按钮 normal / hover / pressed 上宣纸 / 亮泥金 / 泥金 11.6 / 9.3 / 7.8；朱砂按钮印面字 `#f6eedb` normal 5.3、hover 4.3（马善政 24px 大字，AA 大字 ≥3 通过）；提示小笺墨字 10.8；朱砂 `#b0302a` 作字压绢 2.6 / 压纸 4.1（不作浅底正文），朱砂深 `#8e2420` 压绢 3.5 / 压纸 5.6。

**画面上的字（硬规则）**：
1. 港名 / 章节名：垫 `ink_splash_plate`，标题与副题都放进它的安全区（第 5 节），副题用 `OverlayCaption`。**不要拿 `ink_splash_sweep` 垫港名**——它斜着上扬、实心段靠左，副题会落到飞白和天空上（首轮样张「蕃舶云集」实测中位 1.06:1，74% 字形像素低于 3:1）。
2. 其余直接压在画上的小字（页面说明、引言）：一律 `OverlayCaption` / `OverlayText`（焦墨紧描边 + 墨晕，字底实测 ≥ 9.9:1），或者垫 `InkPanel`。普通 `CaptionLabel` / 默认 Label 只许放在墨面板、墨刷底上。
3. 大标题 `TitleLabel` / `HeadingLabel` 自带描边，可直接压画面，但亮处（天空、白墙）仍建议垫墨刷。

两份字体已子集化（`tools/art/subset_fonts.py`：GB2312 全部 + 仓库 data/scripts/scenes/docs 全部用字 + 标点 / 全角 / ASCII / 假名）。文楷 24.2 MB → 3.5 MB；马善政本就只含约 7000 字，5.59 → 5.52 MB。**新剧情文本落地后重跑一次** `python3 tools/art/subset_fonts.py`：源字体默认读 `~/tmp/nk1-art-work/fonts_src/`（或环境变量 `NK1_FONT_SRC` / `--src`），换机器没有源字体就加 `--download`，脚本从上游取回并校验 sha256（文楷 v1.522、马善政 v2.003，地址与哈希写在脚本头部），哈希不符拒绝子集化。输出逐字节可复现。缺字时引擎走系统字体兜底（不会豆腐块，但风格不一致）。马善政缺的十几个生僻字（含「宝祐」的「祐」）由主题里的 fallback 自动落回文楷。

**许可与改名（OFL §3）**：霞鹜文楷上游现行 OFL 声明了保留字体名「霞鹜 / 霞鶩 / 落霞孤鹜 / 落霞孤鶩 / LXGW」，附加许可只放行「不改源码重编译」与「纯网页字体子集」。本作嵌入游戏发行的子集属修改版，所以 `subset_fonts.py` 子集化后把 name 表 ID 1/3/4/6/16/17（全部平台与语言）改成 **NK1 Body Kai**（PostScript 名 `NK1BodyKai-Medium`），版权 ID 0 与作者 ID 8/9 原样保留。文件名 `LXGWWenKai-Medium.ttf` 不变（只是工程路径）。马善政上游未声明保留字体名，沿用原名。完整声明见 `assets/fonts/OFL.txt`（上游版权行逐字照抄，含保留字体名与附加许可段）。

## 4. 接入主题

1. `project.godot` 加一行（UI 线不改此文件，由集成者加）：
   ```
   [gui]
   theme/custom="res://assets/theme/nk1_theme.tres"
   ```
2. 删掉 `scenes/Main.tscn` 里 LeftPanel / InvestigationMode 的 `StyleBoxFlat` override，和 `Main.gd._make_facility_card()` 里手搓的 `StyleBoxFlat`——override 会盖住主题。改成设 `theme_type_variation`（见下表）。
3. Main.gd 里硬编码的 `add_theme_color_override(...)`（0.75 灰、0.65/0.9/0.7 绿等）会破坏色板，建议换成第 2 节色值或 `CaptionLabel`。
4. 重新生成（贴图或主题改动后）：
   ```
   python3 tools/art/build_ui_textures.py          # 约 3 分钟，确定性种子
   <godot> --headless --editor --quit --path .     # 先导入新贴图
   <godot> --headless --path . --script res://tools/art/build_theme.gd
   ```

墨迹的鬃毛笔法（`build_ui_textures.py` 的 `bristle_stroke`）：每根鬃毛起笔按半圆错开（圆头）、终点在笔长后 15–20% 内随机（外侧早收）、临终一段余墨与压力降到 0、收锋时成束向两侧散开；湿段按余墨把鬃毛缝洇满、干段被纸面纹理咬断成灰丝；起笔积墨（`head_pool`）以密度与笔身相加后统一收尾，笔头与笔身没有接缝。

墨迹均为焦墨色 + alpha，叠在画面上用 `modulate` 调浓淡（样张标题屏 wash 用 α 0.55）。**要朱色 / 泥金 / 靛青墨迹**：`modulate` / `self_modulate` 都是乘法，焦墨乘什么都近黑，出不了颜色——改挂 `assets/theme/ink_tint.gdshader`（按贴图 alpha 着 `tint` 色，薄墨略亮积墨略深，modulate 的 alpha 照常调浓淡）。朱砂预置材质 `res://assets/theme/ink_tint_zhu.tres`；别的颜色 `duplicate()` 后 `set_shader_parameter("tint", Color(...))`。样张控件总表最右一枚朱色圆相即此法。

## 7. 游戏里的皮肤：`scripts/core/UiTheme.gd`（2026-09-25 reskin 线）

云端主干的界面全靠 `UiTheme` 静态函数上色（Main.gd / SeaChart.gd / WorldMap.gd 调用），没有挂 `project.godot` 全局主题。换皮肤只动 UiTheme：

- **一个常量切换**：`const SKIN := "juanben"`（默认，绢本墨笔）/ `"yechao"`（旧「夜潮」：深青底、潮光线、珊瑚钮）。夜潮原值逐项留在 `UiTheme.YECHAO` 字典里，函数里夜潮分支逐行照旧；切回夜潮后港口、酒馆截帧与 3cac590 逐像素相同（实测）。
- 颜色 / 字阶仍是 `const`（从字典按皮肤取，编译期定值），调用点照旧写 `UiTheme.GOLD`、`UiTheme.SIZE_FOOT`。
- 绢本 `theme()` 以 `assets/theme/nk1_theme.tres` 为底（滚动条、窗口题签、提示小笺、页签、type variation 全部沿用），再锁文楷正文、字阶与字色。面板、按钮走 `assets/theme/tex/*.res` 九宫；贴图缺了回落委角 `StyleBoxFlat`（`corner_detail = 1` 让圆角退成一刀斜切）。
- 返回 StyleBox 的函数（`panel / plaque / card / shore_door / heading_card …`）返回类型是 `StyleBox`：绢本给 `StyleBoxTexture`，夜潮仍是 `StyleBoxFlat`。
- **宣纸工席**：`UiTheme.paper_card(card)` 给岸门 / 工席 / 货签套宣纸卡，卡里 Label 的字色按 `on_paper()` 换成纸上墨色（宣纸 → 墨、旧绢 → 注文、石青 → 靛青、提示朱 → 朱砂深 …），原石青抬头改马善政大四号，去掉深底用的描边投影。卡每次重排都会再过一遍，后加的字也换得到。小钮（Button）不换，自带墨底 / 朱底。
- 画面上的大字：`port_plaque()`（港名墨刷底 `ink_splash_plate`，笔头 48 / 飞白 231 不拉伸）、`title_logo()` + `sync_title_logo()`（只替「东亚海域立志传」，四方沙盘仍用文字题名）、`title_plaque()`（标题屏淡墨晕）、`frame_portrait()`（立绘旧绢裱框 + 名牌）、`style_overlay()`（直接压画面的小字：焦墨紧描边 + 墨晕）。
- 字色实测：`godot_smoke` 按皮肤断言（绢本：靛墨 / 泥金 / 朱砂 / 石青色相 + 全部深底字色对 INK、纸上墨色对宣纸 ≥4.5:1，印面字对朱砂 ≥4.5:1）；渲染实测用 `tools/art/ShotTour.gd` 的 `--dump-labels / --hide-text / --fill-off`。
