# 节令需求与季节行情

港口行情在 `Economy.price_at_rate` 之外，再乘一层「节令需求」倍数：按月份与货品查表 `Economy.SEASONAL_MUL`，未列的货或月一律 1.0。不入存档、不改存档结构（`Economy.to_dict` / `from_dict` 字段不变），读档后按 `Calendar.month` 自然复原。

## 表

货品：米粮、茶叶、生丝、绢帛、海盐、貂皮、鹿皮、倭扇、经卷。其余货品（瓷、漆器、香药、铁器等）无季节差异，恒 1.0。

- 米粮：春夏季（3–6 月）偏贵、秋收（9–10 月）偏贱。
- 茶叶：春茶新出（4–5 月）价昂、秋后价贱。
- 生丝 / 绢帛：春茧前偏贵、秋新丝上市偏贱。
- 海盐：夏季晒盐丰、价贱；冬季价昂。
- 貂皮 / 鹿皮：冬季御寒需求价昂、夏季价贱。
- 倭扇：夏季需求价昂。
- 经卷：大比之年秋月（8–10 月）需求略昂。

## 史实依据

南宋《梦粱录》《武林旧事》记四时市集与节令商品：春茶、夏扇、秋收米、冬裘；大比之年（1256、1259、1262、1265、1268、1271、1274）秋八至十月贡院唱名，书坊经卷需求略升。行情随月推移仍按 `RECOVERY` 向 1.0 回归，节令只是在月初重新乘上当月倍数。
