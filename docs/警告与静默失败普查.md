## 一、口径与工具

### 为什么不出引擎 WARNING

Godot 4.6.3 的脚本级 warning 由 `GDScriptAnalyzer` 产出，落在 **`ScriptEditor`
底部「Warning」面板**，走 editor 内部通道，**不进 `--headless` 的 stderr / stdout**。
本 lane 实测验证：即使 `--editor --quit-after 8 --path .`、即使把 warning 全开成 error 级
（`gdscript/warnings/* = 2`）也**一条都不打**到 stderr；只有在 X11 编辑器 GUI 里手动开
脚本才可能看到。因此 `--headless --import` / `--headless --export-release` / 运行时
`load()` / `-s res://…` 上收集「全部 warning」在 4.6.3 里是**收集不到**的路径，
别在门禁里再开这条路。

本 lane 用 `/tmp/w20-c5/analysis/scan.py`（Python 静态分析器）替代。判据复刻常
见六类 warning 的 analyzer 口径，verified against docs + Godot 源码：

- 局部 `var / const` 与 `for x in <ident>`：计 `after`（声明行行尾起）对该名
  字的引用数；`_` 前缀豁免；typed declaration（`var x: T`）只报「可能未赋初值」
  不报 unused；
- `UNUSED_PARAMETER`：函数体内名字引用 0 次即报；`_xxx` 前缀豁免；
- `UNUSED_SIGNAL`：私有 signal 未 emit/connect；
- 类级成员：私有 `_x` var 未用（getset-aware — 有 `set = / = get` 绑定即视为用）；
- `INFERENCE_ON_VARIANT`：函数里出现显式类型标注（`-> T` / 形参带 `:` /
  `var x: T`）的函数内，`var y := <expr>` 右端是字典/数组索引、属性访问末尾、
  或调本文件未标注返回值的 func —— analyzer 只知道它是 Variant；
- `UNREACHABLE_CODE`：`return / break / continue` 之后同块缩进仍深的可执行
  行；match case 标签、elif/else 延续、多行 dict/list 字面量、续行 `\`
  都正确豁免。

工具别跟 GdScript 的静态分析 IDE 检查「warning 全收集」对齐「每一处都报」做不到
（引擎有 symbol table + 全 class cache，我没有）；但本工具对**真问题 0 漏**
（见「实测与自证」节），并**对工程常见形状 0 多报**。

### 不动（若干类，给理由）

- **119 处 INFERENCE_ON_VARIANT**：Godot 项目设置默认该类 `enable = false`，
  editor 不打扰，编译速度与正确性都无差；真要改要对每个声明补 typed，超
  本片范围。
- **6 处 UNASSIGNED_VARIABLE**：`var x: T`（typed，无 init）后续按分支赋值——
  Godot 语义合法（T 有默认值），引擎不报。本片口径是「引擎会报的警」，不修。
- **31 处 UNUSED_CONSTANT 跨文件仍被外部引用者**（13 处）：属调色板 / 字号常

  擎不发自 shadowing。改名代价（83 处引用）远大于收益。

  真没扫到。
- **`tools/art/build_theme.gd:83` 已被本 lane 扫描器当 parse 情况报告 0 次**：扫

## 五、静默失败面（逐项复核，非扫）

以下模式**不构成**「该改没改」，但都是面；已逐项看过：

### `if err != OK:` 处理块全部规范

`grep` 全仓 14 处 `!= OK` 全部随即 `push_error / push_warning / printerr /
return`；无一处「只 print 不返回」的静默吞。**零命中**。

### `load()` / `preload()` 未查空

扫了 `= load(` 出现在 `scripts/**.gd` 全部 23 处；所有后续都 `if x == null:
push_error / return / continue` 或注释中明确「此处不可能空且已被 check_assets
门禁钉住」。**零命中隐患**。

### FileAccess / DirAccess / JSON.parse 静默

`SaveLoad.gd / ChartProjection.gd / shot_gate.gd / cs_kit.gd / tour_sheet.gd /
src_probe.gd / build_theme.gd / vision_fill_gen.gd` 8 个文件 14 个 IO 调全部检
查了 `FileAccess.get_open_error() / parse() != OK` 并走 `push_error / return
{status:corrupt} / return false`。**零命中**。
