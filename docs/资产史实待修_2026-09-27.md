## 一、方法（人可复核）

1. **逐张人工过目**：全图缩到 1280 宽看一遍，疑点再按原图像素裁片放大 2–3× 复核；每条结论都有带编号红框的证据图。
   - 证据图：`~/tmp/nk1-art1/evidence/<文件名>.jpg`（整图 + 红框），`<文件名>__<n>.jpg`（第 n 框 2× 放大）；总览 `evidence/sheet0–3.jpg`。
   - 生成脚本：`~/tmp/nk1-art1-venv/bin/python ~/tmp/nk1-art1/evidence.py`（框坐标 = 原图像素，写在脚本里，可逐条改）。
2. **青花直方图筛（试过，不可靠，只作参考）**：`~/tmp/nk1-art1/scan_qinghua.py`，按 32px 格找「钴蓝纹（H 195–250°）+ 相对亮的低饱和白胎」共现。
   用 4 处已知青花罐标定后，**召回只有 1/4**，而且雨景、阴天、夜海误报几百格：油画风 AI 图里的白胎在暗室只有 V≈0.3，跟灰墙、雨幕分不开。结论：自动筛不能代替人眼，本表以人工复核为准。
3. **环境**：系统 python3 没有 Pillow，另建 `~/tmp/nk1-art1-venv`（`python3 -m venv --system-site-packages` + `pip install pillow` → Pillow 12.3.0 / numpy 2.2.4）；本片脚本都用它跑，不碰系统环境。
4. **OCR 没做成**：本机没有 tesseract / 任何 OCR 引擎（`which tesseract` 为空；装系统包超出本片范围，没试）。画中文字（招牌、幡、说明牌）是人工放大读的，读法写在表里。
5. **过场可见性**：按 `data/cutscenes.json` 每镜的 `cam_from` / `cam_to`（中心 x, y, 缩放）估算可见窗口 = 中心 ± 0.5/缩放，判断疑点在不在镜头里（近似，没算 shader 边距）。

严重度：**高** = 外行也一眼看出是后代物 / 现代物 / 简体字，且在港口首页、设施页、序章这类常驻页面；**中** = 懂行才看得出、学界有争议，或只在一个过场 / 次要页里；**低** = 风格化、地理错位、季节矛盾，不伤时代感，可以不改。

## 六、风险与本机做不了的部分

- **本机做不了**：没有生图模型、没有 GPU，§4.1 三张只能由人用 Grok / 出图台重出；没有 OCR 引擎，画中文字全靠人工读；这个会话没进游戏里看修后图（样稿没入库，游戏读的还是原图）。
- **没做**：样稿没写回 `assets/`，没提交二进制，没改 `Main.gd` / 提示词文档 / todo（都超出本片范围，列在上面待议）。
- **判断风险**：「严重度」是按常驻程度 + 一眼可辨程度人工给的，不是量化指标。算盘、骑楼、石狮这几条有史学弹性，已标「争议」或「低」。本表没穷尽所有衣冠细节（幞头 / 官服形制），那得另开一轮专项审查。
- **补区风险**：A / B 在 2× 放大下看是干净的，但游戏里底图会被 `_grade_backdrop` 调色、活背景推拉放大，入库前必须过一次 `qa_p7_screenshots` 截图肉眼看。`fix_bg_signs.py` 和补区脚本都以 HEAD 为底重画同一张图，跑一个就先提交一个（见 §三末）。
- **自动筛失败**：`scan_qinghua.py` 召回 1/4，留着只是为了记下「为什么没用它」，别把它当门禁。
