## 一、方法（人可复核）

1. **逐张人工过目**：全图缩到 1280 宽看一遍，疑点再按原图像素裁片放大 2–3× 复核；每条结论都有带编号红框的证据图。
   - 证据图：`~/tmp/nk1-art1/evidence/<文件名>.jpg`（整图 + 红框），`<文件名>__<n>.jpg`（第 n 框 2× 放大）；总览 `evidence/sheet0–3.jpg`。
   - 生成脚本：`~/tmp/nk1-art1-venv/bin/python ~/tmp/nk1-art1/evidence.py`（框坐标 = 原图像素，写在脚本里，可逐条改）。
2. **青花直方图筛（试过，不可靠，只作参考）**：`~/tmp/nk1-art1/scan_qinghua.py`，按 32px 格找「钴蓝纹（H 195–250°）+ 相对亮的低饱和白胎」共现。
   用 4 处已知青花罐标定后，**召回只有 1/4**，而且雨景、阴天、夜海误报几百格：油画风 AI 图里的白胎在暗室只有 V≈0.3，跟灰墙、雨幕分不开。结论：自动筛不能代替人眼，本表以人工复核为准。
3. **环境**：系统 python3 没有 Pillow，另建 `~/tmp/nk1-art1-venv`（`python3 -m venv --system-site-packages` + `pip install pillow` → Pillow 12.3.0 / numpy 2.2.4）；本片脚本都用它跑，不碰系统环境。
4. **OCR 没做成**：本机没有 tesseract / 任何 OCR 引擎（`which tesseract` 为空；装系统包超出本片范围，没试）。画中文字（招牌、幡、说明牌）是人工放大读的，读法写在表里。
5. **过场可见性**：按 `data/cutscenes.json` 每镜的 `cam_from` / `cam_to`（中心 x, y, 缩放）估算可见窗口 = 中心 ± 0.5/缩放，判断疑点在不在镜头里（近似，没算 shader 边距）。

严重度：**高** = 外行也一眼看出是后代物 / 现代物 / 简体字，且在港口首页、设施页、序章这类常驻页面；**中** = 懂行才看得出、学界有争议，或只在一个过场 / 次要页里；**低** = 风格化、地理错位、季节矛盾，不伤时代感，可以不改。

### 8.1 口径

- **分野**只有两档：
  - **自动修** = 本机用 PIL 脚本就能做（补区 / 重釉 / 贴匾 / 写字，照 `tools/art/fix_bg_signs.py`、`erase_bg_fuzhou_sign.py`、§三 B 法），不用生图。「自动」指不用生图模型，**不是免人眼**：改完照样要进游戏截图看。
  - **必须重出** = 问题物是画面主体 / 主光源 / 散在全图，补区会糊，只能拿生图模型重画。
- **处置**：`改`（排进修图 / 出图）· `不改`（可接受，分野只供将来顺手重出时参考）· `待口径`（等 §七 待议 2 的算盘口径）。
- **证据**三样：① 坐标 = 原图像素框，与 `~/tmp/nk1-art1/evidence.py` 的 `ITEMS` 一字不差，证据图 `~/tmp/nk1-art1/evidence/<文件名>__<n>.jpg`（n 从 0 起，按表内顺序）；② 像素 = 本片用 `~/tmp/nk1-doc3/boxstats.py`（art1 venv 跑，只读 `assets/`）在同一框里量的钴蓝像素数（H 195–250°、S>0.2、V>0.12，与 `fix_customs_jar.cobalt_px` 同阈）和目测描述；③ 依据 = 史实 / 文献的一句话，详见 §二。
- **钴蓝数只作旁证**：油画里的青花大多画成灰蓝（S<0.2），阈值漏得厉害（H1 罐群五六件只命中 21 px）。所以「钴蓝 0」不能推出「不是青花」，青花与否以人眼放大为准（§一.2 同理）。
- **图的实际尺寸不一**（1920×1080 / 1792×1008 / 1672×941 / 1024×1024 / 1192×670），坐标按各图自己的像素，不要换算到 1920 宽。
- **提示词编号**：同一张图的几条共用一段提示词（P1–P22，见 8.3），「重出」时按那一段整张重画。

### 8.4 入库前要知道的两件事（本片核实，没改代码）

- **过场图的清单 sha1**：`assets/cutscene/*.jpg` 由 `tools/art/import_cutscene_bgs.py` 导入，`--data-only` 按 `.import_manifest.json` 的 `out_sha1` 逐张核对（本片在 `9589846` 上跑：`19 张背景合规`）。直接覆盖 `cs_quanzhou_fanfang.jpg` / `cs_world_map_gold.jpg` 会报「与 .import_manifest.json 记录的 sha1 不符」；要改 MANIFEST 里的来源再跑一遍导入，让清单同步（这是 `.py` 改动，属修图 lane）。它不在十三道门禁里，但脚本自称 CI 用。
- **剪影卡底图同源**：`tools/art/build_portraits.py` 的 `ORIGIN_BG` / `FACTION_BG` 拿 `bg_zhangzhou.jpg`（漳州籍）、`cs_quanzhou_fanfang.jpg`（蕃坊 / 大食籍、`fanfang` 阵营）当剪影占位卡的模糊底。重出后不重跑 `build_portraits.py` 就不影响现有卡；重跑的话这些人的卡底会跟着变。
