# 过场分镜

> 线：cutscene_content（过场内容与分镜）。数据：`data/cutscenes.json`（契约 version 1）；背景导入：`tools/art/import_cutscene_bgs.py`；新图：`assets/cutscene/`。
> 引擎：`scripts/cutscene/CutscenePlayer.gd` / `ChapterCard.gd` / `PortBanner.gd`（cutscene_engine 线）。本稿只管画面、字幕、节奏，不写引擎代码。
> 取材：`data/scenes.json` 的 `cg_title` / `cg_world_*` / `cg_narrate_table*` / `cg_decision`、`docs/剧情打磨_序章与终局_2026-09-04.md`、`docs/陈文龙史料调研_2026-09-04.md`、`docs/终局幕本_2026-09-04.md`（台词素材库）、`docs/终局系统化_2026-09-04.md`、`scripts/Main.gd` 各结局结算文本。
> 状态：数据已写入并通过契约门禁；开场与全部结局、四张章节卡已在运行副本里用 Movie Maker 实际截帧看过（见文末「验证」）。

## 〇、约定

- **运镜** `[cx, cy, zoom]`：cx/cy 为 0..1 的画面中心，zoom 1.0 = cover 恰好铺满 1280×720。每镜 `cam_from → cam_to` 都对着本图主体设置，并用门禁复算 `cs_kit.cover_view` 的夹紧：**所有镜头的请求中心与引擎实际中心误差 ≤ 0.012**，不会推到空白处或「想推没推动」。
- **字幕语体**：史笔短句（「是岁乙卯」「控弦之士」「岁无虚日」）只用在开场的天下大势；落到人身上就改白描，第二人称，句子短，先物后情——与序章「先物件后情绪」一致。结局台词逐字取自幕本与 `Main.gd` 结算文本，只删不改，史实原句（「此皆节义文章也，可相逼邪」《诗寄仲子》末联）一字不动。
- **单行规则**：`narration/lower_left` ≤ 22 字、`line/bottom` ≤ 32 字、竖排 `era` ≤ 13 字——超了引擎会折行，门禁直接拒。
- **色调弧**：开场 dusk（金）→ cold（临安雨）→ dusk（博多灯）→ dusk（占城）→ sepia（西域尘）→ dawn（泉州晨）→ dusk（人与海口），冷暖交替，最后收在暮色金。结局各段都从本段主色起，统一收在 dawn/cold 的「一百多年后・福州台江」。
- **转场**：`ink` 用于换「时空」（进入一段、跨年、进入后记）；`fade` 用于同一时空内换景；`cut` 只用在城破（忠肃 2）；`flash` 只用两次——开场末镜的春雷、崖山起火。

## 三、结局过场 `endings`

六个结局名与 `scripts/Main.gd` 的 `ENDING_BG` 键一一对应。「泉州蒲氏的船」与「纲首」**各做一段**：两者在 `Main._on_gangshou_end()` 里文本不同（跟蒲者册上添蒙古官名；未跟蒲者名字排在很后面），画面也就分开——前者落在蒲氏与蕃坊，后者落在自己的船和册子。

除「忠肃」外，五段都收在同一处后记「一百多年后・福州台江，江边没有庙」，画面是 `cutscene/cs_taijiang_dawn.jpg`：晨雾里的江岸、石桥、远帆与渔船，镜头压低在水面与泊船上，不露远处塔楼（「江边没有庙」）。四段 dawn 调同一构图（后记乙版），「未归」用 cold 调、偏向石桥一侧。「忠肃」的后记是有庙的那一版（`bg_temple_gate.jpg`）。这就是幕本「丁 · 尚书公」两行字的画面版。
> 返工记：初稿借用开场末镜的兴化海口（`bg_xinghua_harbor.jpg`）当台江，想做「首尾同一片水」——但兴化海口（莆田，潮间泥滩）与福州台江（闽江江岸）不是一个地方，玩家刚在片头标题下见过这张图标着「兴化海口」，结尾又标「福州台江」，是地理错误，已换图。
