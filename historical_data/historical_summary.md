# 《东亚海域立志传 / 南海立志传》史料汇总报告

本文件汇编了南宋末年（1255–1279年）东亚及南海海域的关键历史时间轴、四大势力、经济与船舶史料，以及人物和据点数据，作为纯学术与事实性的历史参考库。

---

## 1. 宏观时间轴 (1255 – 1279)

本表归纳了南宋末年抗元斗争与海域变局的真实历史时间节点：

| 年份 | 历史纪年 | 关键历史事实 |
| :--- | :--- | :--- |
| **1255** | 宋宝祐三年 | 宋理宗末年，权相贾似道逐渐掌控朝政；蒙古开始筹划全面攻宋，分兵攻蜀及襄樊，边防局势渐趋紧张。 |
| **1259** | 宋开庆元年 | 蒙古蒙哥汗死于四川钓鱼城，忽必烈率军北归争夺汗位。蒙古内部陷入争位斗争。 |
| **1260–1268** | 宋景定/咸淳 | 忽必烈建元大元；宋度宗咸淳四年（1268年），陈文龙高中状元，度宗亲自将其本名“陈子龙”改为“陈文龙”。 |
| **1268–1273** | 宋咸淳四至九年 | 襄阳遭遇长达六年的围攻防守战；宋将范文虎等多次畏战逃跑，最终吕文焕弹尽粮绝降元。 |
| **1273** | 宋咸淳九年 | 襄阳陷落，元军顺江东下，南宋长江防线彻底崩溃。陈文龙因弹劾贾似道罢免无能官员，遭贬退居兴化。 |
| **1274–1275** | 宋德祐元年 | 元军攻逼安庆，贾似道亲率精锐主力迎战，在鲁港被元兵彻底击溃，临安震动。 |
| **1276** | 宋德祐二年/<br>景炎元年 | 临安朝廷投降，谢太后等被俘。益王赵昰在福州登基（改元景炎），建立流亡政权。陈文龙复起为参知政事，兼闽广宣抚使守兴化。 |
| **1276–1277** | 宋景炎元至二年 | 泉州昭抚使蒲寿庚叛宋降元，并在泉州大肆屠杀宋宗室与士人；陈文龙孤军坚守兴化，战败被俘后绝食殉国。 |
| **1279** | 宋祥兴二年 | 崖山海战爆发，宋军全军覆没，陆秀夫背幼帝赵昺投海，南宋宣告覆灭。 |

## 2. 四大势力阵营历史概况

### 🏛️ 南宋朝廷派
*   **核心人物**：宋理宗/度宗、贾似道、文天祥、陈文龙、陆秀夫、张世杰。
*   **历史实态**：中央朝廷面临严重的财政危机与贾似道集团的政治腐败；后期随着临安沦陷，转化为在闽粤沿海及海上的流亡政权。
*   **核心冲突**：朝堂内部的主和与主战派系斗争；强行超发纸币导致的恶性通胀；国防战线的崩溃。

### ⛵ 闽泉海商集团
*   **核心人物**：蒲寿庚、黄/蔡/蒲/曾等泉州海商大姓。
*   **历史实态**：盘踞泉州刺桐港，掌握当时最强大的民间远洋福船队、雄厚的香料及瓷器资源，深度控制市舶司。
*   **核心冲突**：在宋廷征调资产与元军压境的双重压力下，海商集团面临保全家族商网与效忠社稷的生死抉择。

### ⚔️ 日本-博多唐房网络
*   **核心人物**：少弐氏（大宰府守护）、博多唐房的宋朝侨商。
*   **历史实态**：以博多“唐房”为基地，深度参与日宋贸易，垄断硫磺、日本刀与铜的出口。
*   **核心冲突**：镰仓幕府对贸易的控制与唐人自治权的摩擦；同时面临蒙古两次东征日本的战备威胁。

### 🌴 南洋诸国与航线节点
*   **核心人物**：占城君主、三佛齐（巨港）势力、爪哇诸国。
*   **历史实态**：南洋作为宋朝钱币、丝绸、瓷器的主要输入方；巨港、马六甲等地既是商船贸易的中转枢纽，也是海盗多发地。
*   **核心冲突**：室利佛逝霸权衰落后的南洋海域真空；马六甲海峡的通道控制权摩擦。

## 3. 核心经济系统史料支撑

### 3.1 货币双轨制与铜钱外流
*   **铜钱与纸币**：南宋时期使用铜钱（年号钱，足陌1000文，省陌770文）与纸币（会子/关子）双轨制。宋末战事频仍，会子滥发，贬值极为严重。
*   **宋钱外流**：南宋每年有数百万贯铜钱通过贸易流出至日本、高丽及南洋诸国，成为东亚海域的通用“硬通货”，导致大宋国内“钱荒”严重。

### 3.2 史料记载的主要贸易品与单价
*   **日本航线**：
    *   **出口**：瓷器、丝绸、书籍、茶叶。
    *   **进口**：硫磺（约200-300文/斤）、日本刀（约3-5贯/口）、铜矿。
*   **高丽航线**：
    *   **出口**：丝绸、图书、瓷器。
    *   **进口**：人参、马匹（10-15贯/匹）、金、银。
*   **占城/南洋航线**：
    *   **出口**：瓷器、铁器、丝织品、铜钱。
    *   **进口**：占城稻（1.5-2贯/石）、胡椒（约500-600文/斤）、沉香、降真香、象牙。

### 3.3 市舶税收与海禁政策
*   **市舶司抽税**：实行“抽解”和“博买”制度。粗货（瓷、铁）税率较低（约二十税一，即5%），细货（香药）税率极高（可达三十税一至十税三不等）。
*   **蕃坊制度**：泉州、广州等地设蕃坊，集中安置外商，由蕃长管理，提供翻译与牙人担保。
*   **海禁政策**：宋廷在特定边防危机时期会颁布海禁，严禁私人出海 and 走私。

## 4. 船舶与航海技术史料

### 4.1 四大核心造船工艺（福建福船）
*   **水密隔舱**：用隔舱板将船舱分成 5 – 13 个独立不透水的舱区，极大地提高了抗沉性。
*   **鱼鳞搭接**：船壳板采用鳞片式重叠连接。
*   **多层船板**：使用 2 – 3 层交错铺设的厚木板，加固船体。
*   **桐油灰缝**：使用桐油、石灰和麻丝混合的艌料塞缝，作密封防漏处理。

### 4.2 季风约束历史实态
*   **冬季风（10月 – 次年3月）**：东北季风主导，商船乘风由北向南航行（大宋 $\rightarrow$ 南洋）。
*   **夏季风（4月 – 9月）**：西南季风主导，商船由南向北返航（南洋 $\rightarrow$ 大宋，或大宋 $\rightarrow$ 日本/高丽）。
*   **台风多发期**：3月和9月的转帆过渡期极易在台湾海峡及南海海域遭遇强台风灾害。

## 6. 关键港口与地图节点历史定位

1.  **临安 (杭州)**：南宋政治中心，御前市舶司与会子纸币的发行源地。
2.  **兴化 (莆田)**：闽中战略要地，陈文龙抗元根据地与囊山伏击战发生地。
3.  **泉州 (刺桐港)**：中世纪世界第一大港，闽广市舶司与巨型福船制造基地，蒲寿庚大本营。
4.  **福州**：宋端宗（赵昰）即位登基的景炎朝临时行在。
5.  **博多 (日本)**：日宋贸易核心枢纽，设有著名的唐人聚集区“唐房”。
6.  **占城 (越南)**：早熟占城稻与香料（沉香、降真香）的主要产地。
7.  **巨港 (三佛齐)**：南洋航道咽喉，胡椒与锡矿的主要转口贸易港。
